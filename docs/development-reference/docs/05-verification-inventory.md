# 기존 시험 결과의 위치와 현재 활용

아래 수치는 보관된 results.json에서 읽었다. 이번 문서 묶음 작성 중 시험을 재실행하지 않았다.
Python 독립 시험의 통과는 새 Dart 제품의 구현·검증 완료를 뜻하지 않는다.

| 시험 | 내용 | 기록된 통과 | 현재 활용 |
|---|---|---|---|
| `spatial_contract_v01` | 공간 판정 기본 계약 | 20/20 | 공간 판정 사례 |
| `spatial_split_v01` | 배치 제안과 검사 분리 | 23/23 | 기존 배치 유지 사례 |
| `outline_hole_v01` | 글자 윤곽·홀 읽기 전용 감사 | 24/24 | 참고용. 획 사이 홀 배치를 제품 기능으로 도입하지 않음 |
| `result_reasons_v01` | 영역별 판정·다중 사유 | 18/18 | 진단 보존 사례 |
| `result_state_v01` | 완료 결과와 상태 무효화 | 30/30 | 완료 결과 보존·늦은 결과 차단 사례 |
| `result_dxf_v01` | 저장 결과의 DXF 출력 | 23/23 | 기존 출력 사례. 현재 저장·확인 정책과 구분 |
| `manual_flow_v01` | 직접 지정 줄바꿈 | 30/30 | 선택 영역 한정·자동 복귀 사례 |
| `width_floor_v01` | 미등록 자폭 하한 처리 | 24/24 | 계산 불가를 구분하는 사례 |
| `quantity_flow_v01` | 수량과 출력 표현 | 27/27 | 배치 재계산 없이 수량 변경하는 사례 |
| `draft_state_v01` | 미완료 작업 초안 저장 | 34/34 | 초기 구현에서 제외. 과거 시험 근거로만 보관 |
| `mixed_footer_v01` | 직접 지정 본문 유지와 NO/RAT 변경 | 35/35 | 선택 대상 재계산 사례 |
| `manual_pattern_v01` | 직접 지정과 패턴 분리 | 37/37 | 자동 그룹·직접 지정 격리 사례 |
| `pattern_apply_v01` | 패턴 미리보기·취소·적용 | 36/36 | 현재 작업의 명시적 등록 사례 |
| `pattern_lifecycle_v01` | 패턴 수정·삭제 | 31/31 | 검토 결과 적용과 영향 범위 사례 |

시험에는 당시의 범위와 미지원 항목이 있다. 각 results.json의 scope와 안내문을 함께 읽는다.
특히 과거 초안 저장 정책을 현재 요구로 되살리지 않는다. 새 엔진에 임의 글자 윤곽·홀 배치를 추가하지 않는다.
전체 기능 범위는 기능 활용 점검표와 핵심 요구사항·설계 검토를 함께 본다.
이 묶음의 시험 결과만으로 Type3 전체 호환, 새 형상, 실제 장비 생산, 서버 동시성 등이 검증됐다고 판단하지 않는다.
