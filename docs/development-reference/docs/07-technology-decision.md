# 기술 선택 확정

상태: 사용자 확정. 2026-10-18.

Flutter와 Dart로 시작한다. 초기 대상은 Windows 데스크톱이다.
아름다운 UI, 현대적인 개발 방식, 독립 라이브러리 개발, 몇 달 뒤에도 이해할 수 있는 구조를 선택 기준으로 삼았다.
UI와 배치·작업·출력 로직을 Dart 패키지 경계로 분리해 개발 언어와 연결 방식을 단순하게 유지한다.

Rust나 다른 언어 엔진을 초기 구성에 넣지 않는다. 이후 실제 측정 결과나 필수 라이브러리 연동 요구가 생기면 해당 경계에서 다시 판단한다.
배치 엔진 변경이 앱의 업무 코드 전체 수정으로 번지지 않도록 공개 API와 변환 경계를 유지한다.
엔진 버전을 바꿔 사용자에게 배포할 때는 앱을 다시 빌드한다. 독립 개발이 실행 중 엔진 교체를 의미하지 않는다.

화면의 완성도는 프레임워크 선택만으로 보장되지 않는다. 표 편집과 도안 미리보기를 구현할 때 한국어 조합 입력, Excel 붙여넣기,
공백·기호·셀 내부 줄바꿈 보존, 키보드 조작, 확대·선택을 실제로 확인한다.
TrinaGrid는 표 라이브러리 검토 후보이며 채택하거나 이 동작들을 검증한 상태가 아니다.

2026-10-19(한국시간) 제품명은 R-edit로 결정했다. 시작 순서는 문서 저장소 정리 → 순수 Dart 업무 흐름 패키지 → 배치 엔진·DXF → Flutter 앱이다.
