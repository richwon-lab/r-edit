# 리치원 개발 참고자료

2026-10-19(한국시간) 제품명 결정 반영. UI 기술 비교 후 Flutter와 Dart 사용을 확정했다. 새 프로젝트를 로컬에서 Junie와 개발할 때 사용하는 자료다.
기존 제품 프로젝트를 수정하는 작업이 아니라 새로 시작한다. 이 묶음은 문서와 작업 지침이며 실행 가능한 Flutter 앱이 아니다.

제품명은 기존 프로그램의 **R-edit**를 계승한다. 로컬 개발 식별자는 `r_edit`로 통일했다. 기존 저장소는 개인 계정에 있다는 사용자 확인에 따라 조직 저장소 이름도 `r-edit`를 사용한다.
GitHub 조직은 사용자가 설명한 `richwon-lab`을 기준으로 한다. 원격 저장소 목록을 직접 조회한 상태는 아니며, 예시의 `ORG`는 실제 사용할 조직명으로 치환한다.

## 자료의 우선 적용 기준

사용자의 이후 명시적 결정 → DECISIONS.md → 최신 논리 설계 → 기존 요구사항·설계 검토 순서로 해석한다.
Flutter와 Dart는 확정된 선택이다. 저장소 구조와 네이밍 제안은 합의된 기능을 바꾸지 않으며, 다른 언어나 새로운 제품 기능을 추가로 확정하지 않는다.

| 위치 | 용도 |
|---|---|
| `reference/current/` | 논리 설계 최신 저장본, 요구사항 v0.7, 설계 검토 v0.13, 기능 활용 점검표 |
| `reference/previous-plans/` | 예전 첫 구현 계획과 UI 흐름 검토. 현재 착수 지시로 그대로 실행하지 않음 |
| `reference/archive/` | 요구사항·설계 검토의 이전 버전. 변경 경위를 찾을 때 참고 |
| `reference/text/` | 주요 DOCX의 문단·표 텍스트와 점검표의 값 추출본. 원본과 함께 참고 |
| `reference/verification/` | 기존 독립 시험의 results.json과 안내문. 이번에 재실행하지 않음 |
| `reference/user-sources/` | 사용자가 제공한 회사 설명과 검토 가이드 원본 |
| `templates/` | 저장소별 AGENTS.md, 의존성 설정 예시 |
| `INVENTORY.csv` | 포함 파일의 경로·크기·SHA-256 |

특히 예전 첫 구현 계획의 ‘하나의 앱과 저장소’와 UI 문서의 ‘미완료 편집 저장’은 현재 방향과 다르다.
현재 기준은 독립 Dart 라이브러리와 Flutter 앱의 별도 저장소, 전체 제품 정상 또는 작업자 확인 후 저장이다.

DOCX·XLSX 원본은 바꾸지 않고 복사했다. 텍스트 추출본은 이미지·도형·페이지 배치를 재현하지 않으므로 그 부분은 원본을 본다.
이전 시험 코드·DXF·폰트 파일 전체는 이 문서 묶음에 포함하지 않았다. 알고리즘 이식 단계에서 해당 원본을 별도로 가져온다.

## Git 문서 저장소로 사용

이 폴더의 내용을 향후 `r-edit-docs` 저장소에 넣어 개발 기준으로 관리할 수 있다.
현재 작업 대상 저장소에는 해당 `templates/<package>/AGENTS.md`를 루트 `AGENTS.md`로 복사한다.
문서 전체를 각 코드 저장소에 반복 복사하지 않고, 읽어야 하는 문서와 기준 문서 저장소의 커밋을 README에 기록한다.
