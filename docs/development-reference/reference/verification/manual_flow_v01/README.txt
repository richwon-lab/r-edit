리치원 수동 전체 줄 구성·저장·DXF 연결시험 v0.1

실행
1. 새 폴더에 ZIP 전체를 압축 해제합니다.
2. experiment.py를 실행합니다. 예상 결과: passed 30 / total 30, 정상 종료.
3. preview.html에서 수동 지정·한 줄 지정·자동 복귀·MCB46 수동 7줄을 확인합니다.
4. DXF 경로는 results.json의 dxf_directory에 기록합니다.
   재실행마다 DXF, DXF_02 등 새 폴더를 만들며 기존 출력은 덮어쓰지 않습니다.

패키지
기존 DXF 시험과 같이 ezdxf가 필요합니다.
설치가 필요하면 실험 폴더에서 현재 Python 환경으로 실행합니다.
    python -m pip install -r requirements.txt

이번에 연결한 동작
- 원문은 그대로 두고 전체 줄 구성을 명판 ID·영역 ID별로 지정합니다.
- 한 줄 지정도 명시적인 수동 상태로 저장합니다. 자동 경계를 추가하지 않습니다.
- 크기·줄별 자폭·위치는 기존 사각 범위·홀 여유 조건으로 맞춥니다.
- 한 영역의 모든 줄은 같은 글자 크기를 사용합니다.
- 수동 결과는 등록 패턴과 점수 경쟁으로 바꾸지 않습니다.
- 변경 대상 외의 채택 결과는 그대로 보존합니다. 공통 규칙으로 전파하지 않습니다.
- 자동 복귀를 명시하면 기존 자동 정책을 다시 평가하고 선택 영역의 결과만 채택합니다.
- 저장 후 다시 열어도 수동 상태·전체 줄 구성·경고를 유지합니다.
- 수동 결과도 같은 DXF 출력 경로를 사용합니다.

확인한 결과
기존 자동 100행·300영역 결과 변경 없음.
R005의 원문 '"1-2" & "1M2" COIL'을 한 줄로 지정하면 2.3mm, 자폭 약 65.2891%의 참고 결과.
다른 99행과 해당 명판의 NO·RAT 결과는 그대로 유지.
자동 복귀 시 해당 영역의 기존 자동 결과 복원.
MCB46의 기존 7줄을 수동 지정하면 줄 구성 유지, 2.35mm 참고 결과.
디자인상 1줄 고정인 NO 영역을 수동 2줄로 지정하면 배치 없음으로 기록.
그 경우 명판 전체를 DXF에서 제외하고 이유를 기록.

추가 축소 구간의 자폭 하한
이번 수동 맞춤에서는 미등록 하한을 0으로 해석하지 않습니다.
등록된 구간에서 해결하지 못하고 미등록 구간이 필요해지면 계산 불가로 남기며,
미등록 이유와 이미 관찰한 실패 이유를 함께 유지합니다.
R048의 긴 문구 전체를 한 줄로 지정하는 별도 검사로 이 동작을 확인합니다.
기존 자동 엔진 전체의 미등록 구간 처리를 바꾼 시험은 아닙니다.

파일
manual_workflow.py: 완료 결과에서 시작하는 대상 영역별 수동 변경과 자동 복귀.
results.json: 검사 결과.
manual_examples.json / preview.html: 수동 지정과 자동 복귀 사례.
saved_manual_one_line.json: R005의 수동 한 줄 저장본.
saved_manual_with_footer_failure.json: MCB46 수동 7줄 및 R005 NO 수동 실패 저장본.
saved_with_reasons.json: 수정하지 않는 이전 자동 결과 원본.
출력 폴더/01_ManualOneLine: 정상 98개·참고 2개.
출력 폴더/02_FooterFailure: 정상 98개·참고 1개·제외 1개.
각 폴더의 export_report.json: 출력 내역·참고 경고·제외 이유.
두 출력 묶음은 별도 시험이므로 합쳐서 생산하지 않습니다.

범위와 제한
이번 코드는 제품 UI가 아닌 독립 연결시험입니다.
원문을 바꾸지 않는 전체 줄 구성 변경만 다룹니다.
수동 상태의 원문 내용 편집·셀 전체 붙여넣기·실행 취소·실제 화면 조작은 미구현입니다.
원문과 맞지 않는 줄 배열이나 빈 줄을 조용히 수정하지 않고 거부합니다.
이는 빈 명판의 제품 정책을 확정한 것이 아닙니다.
처리는 완료된 현재 결과에서 시작하는 단일 영역 변경입니다.
전체 문서 재계산, 기준 변경과 수동 편집의 결합, 여러 미완료 편집의 병합은 포함하지 않습니다.
수동 상태가 있는 문서에 기존 일괄 계산 함수를 호출하면 이번 시험에서는 명시적으로 거부합니다.
저장본 열기와 DXF 출력에는 재계산이 필요하지 않습니다.
원래 36×36mm·홀 2개 출력 형상, R2000 TEXT 및 글꼴 메타데이터를 유지합니다.
참고 DXF의 고정 '7줄/2.35mm' 시험 주석만 다양한 참고 결과에 맞는 일반 안내로 바꿨습니다.
Type3 확인·현장 조각·인쇄 축소 정책·새 도형 지원은 이번 범위 밖입니다.
