리치원 공간 판정 독립시험 v0.1

1. preview.html을 브라우저에서 열면 미리 생성한 결과를 볼 수 있습니다.
2. 재실행하려면 Python 3.10 이상으로 experiment.py를 실행하세요.
   외부 패키지 설치는 필요 없습니다. Python 3.14에서도 사용 가능한 표준 문법입니다.
3. results.json과 preview.html은 스크립트가 있는 폴더에 다시 생성됩니다.
4. 검사 실패 시 종료 코드 1, 전체 통과 시 종료 코드 0입니다.

범위
- 사각형을 합친 합성 글자 형상, 사각형 명판·텍스트 영역, 원형 홀.
- 홀 반지름과 추가 여유를 합산하고 실제 형상까지의 최소 거리를 비교.
- 지정 여유와 거리가 정확히 같으면 통과. 분수 계산을 사용하므로 이 시험에는 근사 오차가 없습니다.
- 공간 통과 후보 안에서 크기, 주점수, 보조점수, 고정 ID 순으로 선택.
- 모든 후보의 줄 수·정상/참고 우선순위가 같다는 제한 아래 후보 선택을 시험.
- 정상 후보 집합과 참고 후보 집합 모두 같은 공간 검사 함수를 사용.

포함하지 않는 것
- 실제 폰트의 형상 추출·크기 환산, 실제 문구와 자동 줄바꿈.
- 둥근 명판, 일반 곡선, 곡선 근사 오차, 단선체, 테두리·장식의 적용 관계.
- 기존 배치 엔진, 고객 설정, DXF 출력, Type3 비교, 성능 측정.

이 파일의 H 모양은 시험용 도형이며 특정 글꼴의 글리프가 아닙니다.
시험 통과는 위 범위의 계산 계약을 확인한 것이며 전체 공간 엔진 완성을 뜻하지 않습니다.
확인된 설정 글자 크기와 기존 출력 코드는 변경하지 않았습니다.
