리치원 수정 중 작업 저장·복원 시험 v0.1

실행
  python -m pip install -r requirements.txt
  python experiment.py

Python 3.12에서 34/34 통과했습니다. Windows Python 3.14 실행 결과는 별도 확인 대상입니다.
preview.html 및 DXF/는 미리 생성되어 있습니다. 재실행하면 기존 DXF 폴더를
덮어쓰지 않고 DXF_02, DXF_03 등 새 폴더에 출력합니다.

목적
  수정 중인 원문·수동 줄 구성·수량·수량 표현 방식을 저장하고 다시 엽니다.
  이전 완료 결과는 당시 입력과 함께 별도로 보관합니다.
  이전 결과는 조회용 복사본에 '현재 입력의 결과가 아님'을 표시합니다.
  현재 입력에 맞는 계산이 끝나지 않았다면 완료 결과 저장과 DXF 출력은 차단합니다.
  초안 저장과 완료 결과 저장은 서로 다른 동작입니다.

복원 규칙 — 이번 독립 시험의 동작
  완료 상태: 저장된 완료 결과를 그대로 사용합니다.
  수정 후: 수정 입력과 이전 결과를 보존하고 재계산이 필요합니다.
  계산 중: 실행 중 계산을 재개하지 않고 재계산 필요 상태로 엽니다.
  실패: 오류 메시지와 입력을 보존하며 새 계산으로 재시도할 수 있습니다.
  수정 후 취소: 수정 입력을 보존하고 재계산이 필요합니다.
  새 작업: 입력만 복원하며 이전 결과를 만들지 않습니다.
  다시 연 세션은 새 식별자를 사용하므로 이전 프로세스의 늦은 결과를 받지 않습니다.

시험 사례
  기존 자동 기준 100행/300영역은 동일하게 유지합니다.
  자동: R002 RAT를 20A로 수정하고 수량 4, 수량 표기 방식으로 저장합니다.
        다시 열면 재계산 전에는 출력 불가. 재계산 후 20A로 출력하며 수량 4를 표기합니다.
  수동: R005의 기존 원문 전체를 한 줄로 지정하고 수량 2로 저장합니다.
        계산 중 저장한 파일을 다시 열고 새 계산을 실행합니다.
        2.3mm 한 줄 참고 배치를 2개 복제하고 다른 99행 및 NO·RAT 결과를 유지합니다.
  수량은 실제 발주 수량이 아닌 명시적인 시험값입니다.

파일
  draft_store.py: 초안과 이전 완료 결과를 분리해서 저장·복원하는 작은 연결 모듈.
  experiment.py: 상태별 복원, 늦은 결과 차단, 재시도 및 실제 DXF 확인.
  saved_draft_current.json: 계산 완료.
  saved_draft_auto.json: 원문·수량 수정 후 미계산.
  saved_draft_manual_pending.json: 수동 한 줄 계산 중 저장.
  saved_draft_manual_completed.json: 복원 후 수동 계산 완료.
  saved_draft_auto_completed.json: 복원 후 자동 계산 완료.
  saved_draft_failed.json / saved_draft_cancelled.json: 실패/취소 후 입력.
  saved_draft_new.json: 처음 계산하기 전 입력.
  saved_draft_old_engine.json: 이전 시험에서 저장한 엔진 식별 정보를 그대로 보존한 예시.
  saved_with_reasons.json / saved_quantity_excluded.json: 이전 시험 원본, 수정하지 않음.
  source_manifest.json: 재사용 파일 확인 정보.
  DXF/01_AutomaticRetry, DXF/02_ManualRetry: 복원 후 계산한 결과의 정상·참고 DXF와 출력 내역.

연결 방법
  완료 결과를 가진 QuantityJob 또는 아직 계산하지 않은 새 QuantityJob으로
  DraftJob을 만든 다음 수정합니다. 완료 결과를 받으면 DraftJob.finish를 호출해
  당시 입력과 결과를 함께 보존합니다. 계산 후 저장하지 않고 다시 수정하는 경우도 확인합니다.
  save는 초안을 저장하며, reopen_draft는 배치 엔진을 불러오거나 계산하지 않습니다.
  retry_ticket은 기존 자동 계산 또는 한 영역의 수동 변경/자동 복귀 경로만 연결합니다.
  수동 상태와 일반 문구 수정이 섞인 일괄 재계산 등 지원 범위 밖의 요청은 입력을
  유지하면서 거부합니다. 수동 상태를 자동으로 지우고 계산하지 않습니다.

확인 범위와 제한
  기존 배치 엔진·점수·형상·수량 출력 코드는 변경하지 않았습니다.
  실제 UI, 자동 저장 주기, 수동 원문 교체, 여러 수정의 일반적인 일괄 재계산,
  공동 저장 충돌, 앱 강제 종료나 정전 복구, 운영용 저장 형식은 포함하지 않습니다.
  파일 교체 직전 중단 시험은 이전 파일 보존만 확인합니다.
  새로운 프로세스에서 배치 엔진 import를 차단해 저장 상태를 읽는 시험이 포함됩니다.
  실제 스레드나 작업자 프로세스의 자동 재개·중단 구현은 아닙니다.
  편집 이력 전체를 보관하지 않습니다. 현재 초안과 마지막 완료 입력·결과를 보존합니다.
  미리보기 HTML은 결과 확인용 정적 요약이며 Type3의 시각 검증을 대신하지 않습니다.
