리치원 수량·저장 배치·DXF 연결 시험 v0.1

실행
  python -m pip install -r requirements.txt
  python experiment.py

Python 3.12에서 27/27 통과했습니다. Windows Python 3.14 실행 결과는 별도 확인 대상입니다.
미리 생성한 preview.html과 DXF/는 실행 없이도 볼 수 있습니다.
재실행하면 기존 DXF 폴더를 덮어쓰지 않고 DXF_02, DXF_03 등 새 폴더에 출력합니다.

목적
  수량을 바꿔도 저장된 원문·자동/수동 줄 구성·크기·자폭·진단을 유지합니다.
  수량 복제와 수량 표기를 구분하고, 정상·참고·제외 항목의 수량을 보존합니다.
  수량 표기는 명판 바깥 TEST_NOTES에 QTY 숫자로 표시합니다.
  복제는 명판 바깥 TEST_NOTES에 COPY 순번/수량으로 표시합니다.
  명판 내부 TEXT를 수량 표기로 바꾸지 않습니다.

시험 자료와 예상 결과
  실제 100행/300영역 기준 결과를 기존 엔진으로 다시 확인합니다(변경 0개).
  R005만 앞서 검증한 수동 한 줄 참고 배치를 적용한 뒤 수량 시험을 시작합니다.
  R002=3, R005=2, R051=3, 나머지=1은 전부 명시적인 가상 시험 수량입니다.
  실제 주문의 수량으로 해석하면 안 됩니다.
  총 105개: 정상 98행/100개, 참고 2행/5개.
  복제: 정상 도안 100개 + 참고 도안 5개.
  수량 표기: 정상 도안 98개 + 참고 도안 2개.
  별도 미등록 자폭 하한 사례: 주문 9개 중 4개 제외, 복제 도안 5개/수량 표기 도안 2개.
  원래 참고 항목 R051과 수동 참고 항목 R005의 경고·커터 표기를 그대로 유지합니다.

파일
  quantity_flow.py: 수량 변경, 완료 결과 저장/재열기, 수량 방식별 출력.
  exporter_v07.py: 기존 TEXT 출력에 복제 추적 정보와 명판 밖 수량 표기만 추가.
  experiment.py: 회귀 및 실제 DXF 읽기 검증.
  saved_with_reasons.json, saved_manual_cases.json: 이전 시험 원본(수정하지 않음).
  saved_quantity.json: 100행 복제 방식 저장 결과.
  saved_quantity_labels.json: 같은 배치의 수량 표기 방식 저장 결과.
  saved_quantity_excluded.json: 제외 수량 사례 저장 결과.
  DXF/01_Replicated, 02_QuantityLabels: 100행 출력 두 방식.
  DXF/03_ExcludedReplicated, 04_ExcludedLabels: 제외 수량 사례 두 방식.
  각 폴더 export_report.json: 원본 ID·복제 순번·수량·배치 연결·진단·파일 검증 정보.

확인 범위
  수량 변경은 배치 계산을 호출하지 않습니다. 별도 프로세스에서 배치 엔진 import를
  차단한 상태로 저장 결과를 열고 수량을 변경하고 DXF를 출력하는 시험이 포함됩니다.
  기존 계산 엔진 파일을 바꾸거나 과거 결과를 최신 엔진 결과로 재표시하지 않습니다.
  실제 DXF의 TEXT, 크기, 자폭, 상대 위치, 정렬, 외형, 홀, 복제 개수와 QTY 표기를 확인합니다.
  수량 또는 입력 변경 중의 출력 공개 차단, 파일 작성 실패 시 정리, 덮어쓰기 금지,
  저장 중단 시 이전 파일 유지도 확인합니다. 로컬 단일 작성자 조건입니다.

미포함
  제품 구현, 실제 UI, Type3 시각 검증, 인쇄, 여러 프로젝트·자재별 묶음,
  다른 형상, 최적 배열, 공동 저장, 원문 교체 후 수동 상태 처리.
  양의 정수만 시험 입력으로 받습니다. 0/빈칸/취소 수량의 제품 정책을 확정한 것이 아닙니다.
  수량 숫자가 매우 큰 경우의 메모리·실행 시간 한도는 이번 시험에서 다루지 않습니다.
  기존 36x36 두 홀 형상과 R2000 편집 가능한 TEXT를 유지합니다.
  preview.html은 결과 확인용 정적 페이지이며 제품 화면이 아닙니다.
