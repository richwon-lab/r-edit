수동 줄바꿈과 패턴 관리
화면 흐름 검토

리치원컴퍼니 | 2026년 10월 12일 | v0.1

과거 명판에 맞추는 단발성 줄바꿈은 선택한 명판에만 적용합니다. 여러 명판에 반복 적용할 줄바꿈은 표현과 규칙성을 확인한 뒤 패턴으로 등록합니다. 두 작업의 진입점과 적용 범위를 화면에서도 분명히 구분합니다.

동작 원칙은 기존 합의와 독립 시험을 따릅니다. 아래 버튼 이름과 화면 구성은 검토안이며, 제품 UI를 구현하거나 전체 핵심 설계를 확정한 상태는 아닙니다.

2 작업 화면에서 항상 보이는 정보

입력 표와 명판 미리보기의 선택을 연결합니다. 선택한 명판의 식별 정보와 영역 이름, 자동 또는 수동 상태, 현재 입력의 계산 여부를 함께 보여줍니다. 자동·수동은 현재 상태 표시이며 매번 먼저 선택해야 하는 편집 모드로 만들지 않습니다.

기본 동작은 배치 실행, 줄바꿈 편집, 패턴 관리, 작업 저장, DXF 내보내기입니다. 입력 중에는 배치를 계속 바꾸지 않고 명시적 실행으로 반영합니다. 수동 상태의 영역에는 자동 줄바꿈으로 복귀를 제공합니다.

3 수동 편집에서 패턴 등록으로 안내

줄바꿈 편집 옆에는 “여러 명판에도 적용하려면 패턴으로 등록”을 안내합니다. 선택하면 패턴 편집으로 이동해 반복 표현과 줄 구성, 적용 범위를 검토합니다. 단발성 수정에 매번 등록 여부를 묻는 창을 띄우지는 않습니다.

수동 결과 전체를 패턴으로 자동 승격하지 않습니다. 현재 작업의 패턴 적용과 앞으로 재사용할 공통 기준 등록도 별도 동작으로 구분합니다.



수동 줄바꿈 편집 흐름

목표는 선택한 명판의 선택 영역을 과거 도안과 맞추는 것입니다. 원문을 바꾸지 않고 전체 줄 구성을 지정하며, 크기·줄별 자폭·위치는 자동으로 맞춥니다.

1 편집할 영역 확인

예: R028의 본문을 선택하고 줄바꿈 편집을 엽니다. 명판 식별 정보, 영역 이름, 원문과 현재 줄 구성을 표시합니다. 이 창에서는 원문 문자 입력과 줄바꿈 조작을 분리합니다.

2 전체 줄 구성 지정

원문의 문자 사이에서 줄바꿈을 넣거나 제거합니다. 단어 사이만 허용하는 제한은 두지 않습니다. 공백·기호·대소문자를 그대로 보존하며, 줄바꿈을 모두 없애 한 줄로 만든 경우에도 수동 상태로 기록합니다.

3 이 명판에 적용

버튼 이름은 “이 명판에 적용”으로 제안합니다. 지정한 줄을 고정한 채 맞춤 계산을 실행하고, 정상 결과 또는 참고 결과와 이유를 보여줍니다. 자동으로 다른 위치에 줄바꿈을 더하지 않습니다. 공간 조건 위반이나 계산 불가는 적용 가능한 배치로 표시하지 않습니다.

4 편집 취소와 자동 복귀

편집창 안의 임시 변경은 “취소”로 버리는 안입니다. 이는 아직 적용하지 않은 편집안을 닫는 동작입니다. 이미 채택한 수동 구성을 해제하려면 “자동 줄바꿈으로 복귀”를 별도로 실행하고 선택 영역만 다시 계산합니다. 수동 원문 교체와 적용 후 실행 취소는 아직 상세 설계가 필요합니다.

확인할 화면 사례

R028을 수동으로 바꿔도 다른 99개 명판은 즉시 바뀌지 않아야 합니다. 이후 R027 자동 본문을 수정할 때도 R028의 수동 배치를 통일 기준으로 사용하지 않습니다. 수동 유지 여부와 계산 상태를 따로 표시합니다.



패턴의 등록 수정 삭제 흐름

패턴 관리는 반복 표현의 배치 규칙을 다루는 화면입니다. 현재 시험에서 지원한 범위는 현재 작업의 자동 본문이며, 수동 본문은 적용 대상에서 제외합니다.

1 규칙과 범위 편집

문구를 선택하거나 직접 입력합니다. 문구 안의 어느 위치에서 줄을 나눌지, 앞뒤 문구와 같은 줄을 허용할지를 구분해 보여줍니다. 최근 시험은 앞뒤 문구와 분리하는 독립 블록만 지원했습니다. 다른 결합 방식은 지원된 것처럼 표시하지 않습니다.

버튼은 “영향 확인”으로 제안합니다. 확인 전에는 작업의 패턴이나 채택 결과를 바꾸지 않습니다. 수정은 기존 패턴의 문구와 변경 전 규칙을 표시하고, 삭제는 제거할 규칙을 먼저 보여줍니다.

3 확인한 결과 적용 또는 취소

버튼은 동작에 따라 “등록하고 적용”, “수정하고 적용”, “삭제하고 재계산”으로 구분합니다. 적용하면 확인한 규칙과 결과를 함께 반영합니다. 취소하면 현재 작업을 유지합니다. 미리보기 이후 입력·수량·규칙이 바뀌거나 작업을 다시 열었다면 새로 영향 확인을 실행합니다.

삭제 안내 문구

“이 패턴을 제거하고 현재 문구로 자동 배치를 다시 계산합니다. 수동 줄바꿈과 원문 수정 내용은 유지합니다.” 삭제는 과거 배치로 되돌리기가 아닙니다. 모든 일치 항목이 수동이면 규칙만 지우고 배치는 유지합니다.

2 공통 기준으로 등록하는 후속 흐름

현재 작업에서 확인한 규칙을 다른 주문에도 쓰려면 별도 “공통 기준으로 등록”으로 연결합니다. 고객사와 필요한 내부 구분을 명시하며, 프로젝트가 바뀌었다는 이유만으로 재사용을 끊지 않습니다. 디자인이 다르면 각 디자인의 공간·크기·자폭 조건에서 다시 평가합니다.

공유 변경에는 기존 권한 원칙을 연결합니다. 허용된 디자인 공유는 도안자가, 공통 핵심 변경의 최종 확인은 관리자가 맡습니다. 채택 후에도 진행 중 작업과 완료 결과를 자동으로 바꾸지 않습니다. 이 흐름의 범위 식별·권한 구분·실제 저장 연결은 아직 구현하지 않았습니다.

3 다음 구현 전에 정할 사항

우선 공통 기준 등록에서 고객사·내부 구분·디자인의 연결과 적용 범위 표시를 확정해야 합니다. 수동 상태에서 원문을 교체하는 동작, 편집창 임시값의 저장·닫기 처리, 적용 후 실행 취소도 남아 있습니다. 현재 시험의 충돌 차단을 모든 포함 패턴에 대한 최종 정책으로 확대하지 않습니다.

검토 근거와 완료 범위

설계 근거: 핵심 요구사항 설계 검토 v0.13의 K05·K08·K09·K10 및 15·18·19·25장, 2026년 10월 12일의 수동 작업과 패턴 분리 결정. 최근 독립 시험은 manual_pattern 37/37, pattern_apply 36/36, pattern_lifecycle 31/31을 사용자 PC에서 확인했습니다.

저장·재열기·DXF 일치는 각 시험 범위에서 확인했습니다. 실제 UI 조작, 고객사 간 공유, 임의 형상과 전체 핵심 설계의 완료를 뜻하지 않습니다. 이번 문서는 그 경계를 유지하면서 다음 화면 검토에 사용할 작업 흐름을 정리합니다.
