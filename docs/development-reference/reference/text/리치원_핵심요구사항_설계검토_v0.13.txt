핵심 요구사항과 설계 검토

2026년 10월 11일 | v0.13 | 자폭 동점 처리와 그룹 후보 보존 47~49장

핵심 프로세스는 요구사항과 설계를 검토한 뒤 구현한다. 목적은 반복 주문의 일관성과 문구 보존을 지키면서, 소량도 편하게 처리하고 줄바꿈·자폭 수작업을 줄이는 것이다. 이 문서는 합의된 요구와 구현 전에 결정할 동작을 분리한다.

이번에 결정한 개발 순서

요구사항 기준본 → 핵심 설계와 검증 사례 → 검토 및 확정 → 구현 → 검증 순서로 진행한다. 기존 첫 구현 작업계획 v0.1의 W01 착수는 핵심 설계 검토 이후로 변경한다. 독립 기능은 입출력·완료 기준과 핵심 설계에 대한 의존성이 명확할 때만 선행 개발할 수 있다.

문서의 위치와 현재 상태

전체 범위와 기존 요구 ID는 요구사항 정의서 v0.7을 참고한다. 이번 합의가 바꾼 R14·R15의 수동 조정, R17·R26의 과거 선택, R24의 커터 처리, R32의 레이어 결합은 본 검토본을 우선한다. 구현 순서도 이번 워터폴 합의를 따른다. K 번호는 검토용 연결 번호다.

완료 판단의 기준

원문·수량·형상 보존, 필수 공간 조건, 동일 조건의 일관성, 과거 결과 유지, 출력 일치는 필수다. 소량은 버튼 실행 직후에 가까운 반응을 목표로 하고 수백 개는 작업량에 따른 대기를 허용한다. 초 단위 수치와 작업시간 단축률·허용 수정률은 미정이다. 문구 준비부터 Type3 마무리까지 비교하며 생성 속도만으로 성공을 판단하지 않는다.

1 디자인과 입력의 합의된 요구

K01 디자인 작성과 문구 배치 분리  R01~05 R29

프로그램에서 일반 명판을 직접 만들거나 DXF를 가져와 수정한다. 임의 개수·위치의 홀과 여러 텍스트 영역, 테두리·장식을 포함한다. 문구 배치 중에는 외형·홀·텍스트 영역을 고정한다. 홀이나 영역이 바뀌면 다른 디자인으로 다룬다.

확인할 사례: 십자형 4홀, 3·5·6홀과 복수 문구 영역을 유형 선택에 갇히지 않고 구성한다. 외곽만 키울 때 다른 도형이 의도 없이 변하지 않는다.

K02 도형의 의미와 배치 영향  R02 R30 R35

같은 원이라도 홀·장식일 수 있으므로 사람이 역할을 지정하고 재사용한다. 기본 허용 경계는 외곽이며 필요하면 테두리 등의 안쪽을 지정한다. 홀 회피는 홀 크기보다 작아질 수 없다.

확인할 사례: 홀과 장식 원을 구분한다. 도형·역할·회피 여유·적용 영역·출력 포함 여부를 보존한다. 미지정 도형의 처리와 지원 객체 범위는 상세 설계에서 확정한다.

K03 문구와 수량 입력  R06~08 R31

한 행은 명판 항목 하나이며 여러 문구 열을 디자인의 텍스트 영역에 연결한다. 직접 입력과 Excel식 범위 붙여넣기, 표와 미리보기의 선택·편집 연결을 지원한다. 반복 문구 행을 임의로 합치지 않는다.

확인할 사례: 세 문구 영역과 수량을 함께 입력한다. 같은 문구가 여러 행에 있어도 수량과 수동 수정이 섞이지 않는다. 영역 이름 변경으로 문구 연결이 끊기지 않게 설계한다.

K04 원문과 빈 명판  R07 R13

문자·기호·띄어쓰기·대소문자를 임의로 교정하거나 누락하지 않는다. 의도적인 빈 명판을 허용한다. 고객사·프로젝트 사전과 이번만 무시를 구분하여 오타 의심을 확인한다.

확인할 사례: 배치용 줄바꿈과 원문 편집을 구분한다. 빈 영역을 일률적으로 차단하지 않는다. 빈칸 의도 확인의 구체적인 조작은 아직 미정이다.

K05 명시적인 배치 실행  R14 R15 R31

입력 중에는 줄바꿈을 계속 바꾸지 않고 배치 버튼으로 반영한다. 문구·줄바꿈은 사람이 수정할 수 있지만 자폭·글자 크기·위치는 자동화가 맞춘다. 디자인 준비에서 기본값과 조정 기준을 정하며, 명판마다 자폭·크기를 직접 고치는 흐름은 핵심 범위에서 제외한다.

확인할 사례: 사람이 지정한 전체 줄 구성을 유지하고 다른 위치에 자동 줄바꿈을 추가하지 않는다. 크기·자폭·위치는 다시 맞춘다. 한 영역의 모든 줄은 같은 크기다. 미반영 결과는 최신 출력으로 취급하지 않는다. 상세 동작은 15·24~26장을 따른다.

2 자동 배치와 기록의 합의된 요구

K06 필수 조건과 조각 조건  R10 R11 R24 R30

홀·허용 경계와 원문 보존은 정상·참고 결과 모두 지킨다. 조각은 같은 디자인의 같은 텍스트 영역끼리 기준 커터를 최대한 유지한다. 정상 범위에서 해결되지 않으면 줄 수 확대와 필요한 크기 축소를 검토한다. 적용 자폭 하한을 유지하며 가능한 큰 글자를 찾고, 기준 커터의 크기 조건 미달은 경고한다. 인쇄에는 커터 평가·제한·경고를 적용하지 않는다.

K07 스타일과 후보 선택  R10 R11 R22

기본 글자 크기는 사람이 정한다. 한 영역의 모든 줄은 같은 크기이며 자폭은 줄별로 조정한다. 정상 자동 배치는 디자인의 선호 줄 수 범위를 먼저 지키고, 그 안에서 가능한 큰 글자 크기를 유지한다. 줄바꿈과 자폭으로 맞추다가 커터 기준을 지키기 어려우면 크기를 축소한다. 범위 밖 배치는 참고 결과와 경고로 구분한다. 75×25·1~3줄·4.5mm·80%는 특정 디자인 조건이다.

K08 패턴과 과거 배치  R09 R17 R22 R26

일반 주문은 고객 구분·디자인별 현재 기준을 사용한다. 과거 결과가 여러 개여도 매번 선택하지 않는다. 공통 패턴은 고객사·선택적 내부 구분 안에서 머리말·꼬리말·중간 구절을 참고하며 프로젝트 차이만으로 끊지 않는다. 특수 주문·폐기 기준의 기록이 일반 기준에 섞이지 않게 한다. 과거 도안은 보존하고 재사용·참조 대상의 선별 방식은 D04에서 정한다. 초기 문구 분석을 통한 패턴 제안과 사용자의 직접 등록을 모두 지원한다. 18~21장에서 요구와 검토 초안을 구분한다.

K09 초기 기준 조율과 공유  R18 R19 R32~34

여러 리치원 기준과 고객사 기준을 조합한다. 상위 레이어의 지정값을 우선하고 미지정 항목은 아래 값을 따른다. 현재 기준은 처음 충분히 조율해 쓰며 의도적으로 교체한다. 마지막 출력이 자동으로 기준이 되지는 않는다. 허용 범위의 디자인 공유는 도안자가, 공통 핵심 변경의 최종 확인은 관리자가 맡는다. 우선순위·출처는 확인 가능해야 하며 상세 UI는 보류한다.

K10 저장과 출력  R16 R17 R20 R25~28 R34

입력·디자인·적용 기준과 채택 배치·수동 줄바꿈·경고를 남긴다. 일회성 작업 저장과 공통 등록을 분리한다. 확정 배치를 편집 가능한 줄별 TEXT로 출력하며 기본 DXF는 R2000이다. 수량 복제·표기를 지원하고 프로젝트·자재 구분을 유지한다. 커터 경고 항목을 별도 배치해도 소속과 수량은 보존한다. VND 등 연결 파일은 사람이 참고하며 내부 수정을 추적하지 않는다.

검증 묶음: 행 순서와 담당자에 무관한 결과 / 현재 기준과 특수 주문 분리 / 인쇄·조각 / 수동 줄바꿈 후 자동 맞춤 / 저장한 과거 결과 보존 / 경고 전달 / 수량 일치. 기존 C01~C09는 변경된 요구에 맞춰 후속 상세 검증안을 갱신한다.

지금 보류해도 되는 항목

세부 화면 배치, 서버·공유 저장·업데이트 도구, DXF·폰트 추가 기술 검증은 지금 확정하지 않는다. 다만 관련 구현을 시작하기 전에는 지원 범위와 입출력 계약을 정하고, 현장 배포 전에는 실제 PC·Type3에서 검증한다. 보류를 검증 완료로 해석하지 않는다.

고객 직접 접속은 보류하고 보고서 내보내기를 후속 검토한다. 업무관리·sERP·가격 계산·배송 추적은 핵심 설계에 끌어들이지 않는다. NC·DWG 직접 지원·VND 소급 해석·외부 수정 추적은 제외 범위를 유지한다.

D03 자동 맞춤과 D04 현재 기준 운영

줄바꿈 지정 후 자폭·크기·위치는 자동 맞춤한다. 개별 수정의 계속 적용 여부는 도안자가 선택한다. 일반 주문은 현재 기준을 사용하고 특수 결과가 자동으로 기준이 되지는 않는다. 기준 교체의 적용 시점과 참고 기록 재평가 절차는 5장, 수정 반영은 8장에 정리했다.

핵심 구현에 들어가는 조건

D01~D06의 주요 동작과 기대 결과를 합의하고, 디자인·입력·수동 수정·채택 결과·출력의 데이터 관계 및 처리 경계를 문서화한다. 정상 사례뿐 아니라 충돌·실패·재배치 사례도 예상 결과가 정해져 있어야 한다. 미해결 항목이 남으면 영향받는 구현은 착수하지 않고 독립 작업만 진행한다.

변경 관리와 선행 개발

변경은 기존 요구 ID, 변경 이유, 영향받는 동작과 검증 사례를 갱신한 뒤 코드에 반영한다. 간단한 수정까지 별도 조직이나 승인 도구를 만들지는 않는다. 독립 기능은 Excel 붙여넣기 해석이나 화면 확대·이동 등이 후보이며 아직 착수 결정은 아니다. 시험 코드는 제품 구현과 분리한다.

근거: 요구사항 정의서 v0.7, 첫 구현 작업계획 v0.1, 2026년 10월 3~5일 논의. 18~21장은 패턴 준비 요구, 22~23장은 포함 관계의 최신 결정과 검증 결과다. 문서 개정은 핵심 구현 착수나 현장 검증 완료를 뜻하지 않는다.

같은 표현을 포함하는 것과 같은 명판 계열인 것은 다르다. 패턴은 어느 고객 범위에서 어떤 문구의 어떤 경계를 맞출지로 기록하는 초안이다. 공통 단어 하나나 부분 포함만으로 전체 배치를 연동하지 않는다. 관계가 연결된다는 이유만으로 모든 문구를 한 계열로 확장하지 않는다.

S/G ALARM … STOP P/B에서는 꼬리말 앞 경계를 맞출 수 있다. 꼬리말이 없는 S/G ALARM BUZZER까지 두 줄로 강제하지 않는다. 관련 문구라도 지나친 축소나 줄 수 증가가 생기면 경계 통일을 완화할 수 있다. 세부 인식 기준과 평가 관계는 미정이다.

기준 준비와 일반 주문의 차이

기준 준비에서는 관련 사례를 함께 재평가한다. 일반 주문의 새 문구는 확정 기준에 최대한 맞추며 기준을 자동 교체하지 않는다. 약한 관계마다 작업자에게 선택을 요구하지 않는 방향이다. 이미 확정한 패턴과 일회성 수정은 구분한다.

시험과 반영 절차

1. 수정본을 보존한다. 원래 결과와 수정 결과의 줄 수·크기·자폭, 관련 패턴과 설정 출처를 비교한다. 수정 배치가 후보에 없었다면 평가 점수만 바꾸지 않고 후보 생성부터 검토한다.

2. 규칙 변경안을 별도로 시험한다. 검증 대상의 수동 줄바꿈 고정과 과거 배치 직접 재사용을 제외한다. 정상적인 표현 정보와 패턴 참고까지 버린다는 뜻은 아니다. 실제 작업 중인 수정본은 바꾸지 않는다.

3. 수정한 문구, 관련 문구, 유지해야 할 반례와 긴 문구를 함께 비교한다. 시험 취소 시 기존 상태를 유지하고 채택 시 시험한 설정과 결과를 함께 반영한다.

11 영역별 조각 기준

적용 대상은 CNC 조각이다. 글자를 온전히 조각하고 뭉개짐을 피하는 것이 우선이며, 가능한 커터 중 글자 크기에 비해 지나치게 작아 가공이 오래 걸리는 선택도 피한다. 실제 CAM·NC 생성과 생산자의 커터 지정은 이번 범위 밖이다.

폰트별 기준과 근거

HY세고딕·HY특태고딕·HY견고딕·Arial·Arial Bold에 위 초기값을 공통 적용한다. 폰트별 수정과 신규 등록을 허용하고, 등록값이 없으면 공통 기본값을 사용한다. 기존 PH 1.5T·일부 2T 작업 경험과 이번 사용자 지정에서 나온 운영 기준이며 가공의 물리적 보증은 아니다.

이전 3mm·60% 예시는 이번 표로 갱신한다. 기본 자폭은 디자인 목표이며 축소 하한과 다르다. 적용 중인 기준 커터의 자폭 하한을 유지하면서 가능한 큰 글자를 찾는다. 참고 배치에서도 글자 크기를 살리기 위해 자폭 하한을 낮추지 않는다. 기존의 자폭 미달 후보를 경고만으로 채택하던 시험 방향은 28장의 최신 결정으로 대체한다.

정상 범위에서 글자 크기를 우선 유지

디자인의 정상 줄 수 범위에서 기본 글자 크기를 최대한 유지하고 줄바꿈·자폭을 조정한다. 커터 자폭 기준을 만족하지 못하면 영역 전체 크기를 줄여 다시 맞춘다. 정상 후보 간 크기·자폭의 균형 점수만으로 더 작은 글자를 선택하던 방향은 이 순서로 대체한다. 같은 크기 후보의 세부 평가는 미정이다.

정상 후보가 없으면 줄 수 확대와 필요한 크기 축소를 검토한 참고 결과를 제공한다. 참고 줄 수를 4줄로 고정하지 않는다. 적용 자폭 하한은 유지하고 기준 커터의 크기 조건 미달과 선호 줄 수 초과를 경고한다. 기준 커터와 그 하한을 자동 교체하지 않는다. 조건을 지키는 후보를 만들지 못하면 원인을 표시하며 조건을 몰래 완화하지 않는다.

초기 기준을 조율하는 곡선 편집

그래프를 통한 감점 조율은 남겨두되, 정상 후보의 글자 크기 우선순위를 점수로 뒤집지 않는다. 곡선 모양·조절점·가중치와 예외 참고 후보의 세부 순위는 아직 미정이다. 기존 점수 비교 시험은 탐색 기록이며 채택한 생산 기본값이 아니다.

조작 중 그래프는 즉시 바뀔 수 있지만 명판 재배치는 명시적인 실행으로 갱신한다. 곡선 형태와 규칙 간 상대적 중요도는 구분한다. 크기·자폭은 연속값으로, 줄 수는 정수 위치에서 평가한다. 모든 종류의 규칙을 곡선으로 표현하지 않는다.

다음 설계에서 확정할 사항

정상 배치 순서와 예외 참고 결과의 구분은 24장을 따른다. 참고 후보의 가독성 비교·동점 처리·효율적인 탐색과 인쇄의 축소 기준은 후속 설계한다. 커터 기준 이탈은 공간 침범과 구분하고 줄별 문제를 평균에 숨기지 않는다.

현재 단계는 요구와 검증 기준 정리다. 규칙 조합·탐색·형상 판정 등의 미완료 설계는 유지하며 이번 개정으로 핵심 구현을 시작하지 않는다.

먼저 정상 줄 수 범위에서 큰 글자를 유지하며 줄바꿈·자폭을 조정하고, 커터 기준을 지킬 수 없으면 크기를 줄인다. 그래도 안 되면 참고 배치와 경고를 제공한다. 작은 커터면 조각 가능하다고 자동 확정하지 않는다.

ED01: 자동 문구 수정 후 재계산. ED02: 수동 전체 줄 구성과 한 줄 지정 보존. ED03: 다른 명판·영역에 영향 없이 자동 복귀. ED02·ED03의 일부는 26장의 독립 시험에서 확인했다. 화면 통합과 수동 상태의 문구 교체는 아직 검증하지 않았다.

가져온 도형과 불완전한 경계

공간 검증 사례

글자 기준점만 검사하거나 경계 밖 글자를 잘라 맞추지 않는다. 화면의 회피 범위와 실제 판정을 일치시킨다. 곡선 계산·글자 형상 정확도·수치 오차·속도는 후속 기술 설계 대상이며 위 사례는 아직 실행하지 않았다.

18 초기 패턴 준비와 직접 등록

목표는 고객 문구를 초기에 충분히 살펴보고 일관된 배치 기준을 준비한 뒤, 일반 주문에서 손쉽게 재사용하는 것이다. 작업할 때마다 담당자가 패턴을 다시 고르거나 결과를 계속 학습시켜야 하는 운영을 전제로 하지 않는다.

확인된 요구

고객의 문구를 모아 반복 표현과 공통 구성을 분석하고, 배치 기준으로 채택할 패턴 후보를 제안한다. 머릿말·꼬릿말·중간 표현을 모두 대상으로 한다. 사용자는 후보를 선택할 수 있고, 작업 경험이나 고객 요청으로 표현을 직접 추가할 수도 있어야 한다. 반복 횟수가 적다는 이유로 직접 등록을 막지 않는다.

패턴은 고객사와 필요 시 내부 팀 등 구분 범위에서 관리한다. 프로젝트가 다르다는 이유만으로 참조를 끊지 않는다. 패턴을 공유하더라도 홀·텍스트 영역이 다른 디자인의 배치 결과를 그대로 이식하지 않고 각 디자인 조건에서 평가한다.

후보 제안과 직접 추가의 통합

자동 분석에서 채택한 패턴과 직접 추가한 패턴을 같은 목록에서 관리하는 방향으로 검토한다. 문구 선택 또는 직접 입력으로 추가하고, 적용 범위·원하는 줄 구성·근거를 확인할 수 있어야 한다. 후보의 출현 횟수는 참고 정보이며 자동 채택의 근거가 되지는 않는다.

“한 줄로 묶기”와 “앞뒤에서 줄을 나누기”를 구분한다. 표현만 등록해도 사용자의 배치 의도가 모두 정해지는 것은 아니다. 실제 명판의 적용 전후 모습으로 의미를 확인할 수 있어야 한다. 화면 구성과 세부 조작은 미정이다.

19 패턴 적용과 공유의 동작 초안

이 장은 구현 전 검토할 동작 초안이다. 일반 작업자는 준비된 기준을 사용하고, 기준을 만들거나 바꾸는 시점에 적용 범위와 영향을 확인한다.

개별 작업과 지속 적용의 구분

직접 줄바꿈하거나 패턴을 추가했다고 다른 작업의 기준이 자동으로 바뀌지 않는다. 이번 작업의 조정과 계속 사용할 기준에 반영하는 동작을 구분한다. 사용자가 지속 적용을 의도했을 때 반영하며, 허용 범위 안의 디자인 재사용 등록과 타인에게 영향을 주는 공유 기준 변경을 구분한다. 공유 변경에는 앞서 정한 권한·승인 원칙을 적용한다.

20 후보 평가와 패턴 비교의 검토 결과

후보를 남기는 기준

이 절은 크기·자폭 균형을 비교하던 당시 시험 기록이다. 현재 정상 배치는 24장의 선호 줄 수 범위와 글자 크기 유지 우선순위를 따른다. 같은 우선순위 안에서 줄바꿈 위치·패턴 관계가 다른 후보를 남기며, 지역적으로 먼저 선택한 후보가 묶음 전체의 통일감을 막지 않도록 검토한다. 탐색 범위·후보 축소·동점 처리는 아직 설계 대상이다.

보류한 판단

포함 관계라는 이유만으로 패턴을 일괄 제외하지 않는다. 242·243번처럼 연결을 원하지 않는 사례와 번호·공통 꼬릿말을 맞출 사례를 함께 다뤄야 한다. 자동 탐지의 충분한 근거, 후보 제안의 정렬·묶음 방식, 겹치는 패턴의 세부 결합은 미정이다.

STOP P/B는 발주 19행·15종 문구에 나타난다. 이 중 EM'CY 계열 11행과 ALARM 계열 8행의 기대 결과를 22장에서 구분해 채택했다. 출현 빈도와 관계없이 직접 등록할 수 있으며, 다른 고객사나 디자인에 이번 구성을 일괄 적용하지 않는다.

곡선식·가중치·조절점 개수, 커터 경고와 금지 구역의 연결, 충분한 후보를 유지하면서 반응 속도를 확보하는 방법은 후속 설계 대상이다. 75×25 외에 한 줄 타이틀·복수 영역·다른 홀 배치·인쇄에서도 검증해야 한다. 이번 개정으로 설계 검토를 완료하거나 핵심 구현에 착수하지 않는다.

최근 논의의 상태

확인된 요구: 초기 후보 제안·직접 등록·평소의 자동 재사용. 채택한 기준 사례: 두 STOP P/B 패턴의 포함 관계와 19행의 줄 구성(22장). 검토 초안: 통합 목록·공유·준비 완료 조건. 미확정: 일반 인식·결합 알고리즘, UI, 점수, 성능. 시험 결과와 구현 완료를 구분한다.

22 포함되는 패턴의 배치 기준

MRCE 3448 BCC의 75×25 검토 사례에서 STOP P/B와 EM'CY STOP P/B를 각각 등록한다. 두 표현은 독립된 한 줄 배치를 우선한다. EM'CY 전용 패턴을 추가하지 않기로 했던 중간 판단은 아래 결정으로 대체한다.

채택한 동작

겹치는 부분에는 EM'CY STOP P/B를 적용하고 작은 패턴의 배치 요구를 중복 적용하지 않는다. ALARM 계열에는 STOP P/B를 적용한다. 두 표현 모두 앞뒤 문구와 분리된 줄을 우선하되 줄 번호와 전체 줄 수는 고정하지 않는다.

배치 선호는 원문·공간 조건을 지키며 크기·자폭·커터 조건과 함께 평가한다. 모든 고객사에서 긴 패턴이 항상 이긴다는 규칙은 미정이다.

75×25 형상·글자 경계 상자와 3mm·자폭 58% 이상의 후보로 시험했다. Type3 치수·조각 품질은 미검증이다. 점수·알고리즘은 미확정이며 다른 디자인도 후속 검토한다.

24 최신 배치 결정과 예외 처리

2026년 10월 6일 대화 반영. 이 장은 이전의 크기·자폭 균형 평가와 4줄까지만 참고 결과를 만드는 시험을 대체한다. 75×25 조건은 해당 디자인에만 적용한다.

정상 배치

디자인의 선호 줄 수 범위 안에서 커터 조건을 만족하는 후보를 먼저 찾는다. 그 안에서 가능한 큰 글자 크기를 유지하고 줄바꿈·줄별 자폭을 조정한다. 크기 축소를 검토하는 자폭은 기준 커터의 등록값과 연결한다. 패턴 통일 때문에 정상 줄 수 범위를 벗어나지 않는다.

예외 참고 결과

정상 범위로 해결되지 않으면 필요한 줄 수 확대와 축소를 검토한다. 4줄 상한이나 기준 커터의 최소 크기로 참고 후보를 일괄 삭제하지 않는다. 다만 적용 자폭 하한은 유지하면서 가능한 큰 글자를 찾는다. 선호 줄 수 초과와 커터 크기 미달을 알리고 홀·허용 경계·원문을 보존한다. 자폭 하한을 어긴 결과를 채택하는 이전 시험은 28장의 최신 결정으로 대체한다.

참고 후보의 세부 순위는 미확정이다. 28장의 MCB46 시험은 고정된 7줄·영역·줄 간격에서 자폭 하한을 지키는 최대 크기를 찾은 사례다. 모든 줄 수·영역·간격을 대상으로 하는 일반 최적화가 완료된 것은 아니다. 인쇄의 축소 판단 기준은 후속 설계한다.

엔진 입력과 결과의 초안

입력 단위는 같은 디자인의 문구 묶음이다. 디자인 형상·영역·회피 조건, 우선순위가 정리된 규칙, 원문, 수동 전체 줄 구성, 선택한 과거 패턴과 실제 글꼴 정보를 전달한다. 엔진이 계산 도중 공용 저장소의 최신 기준을 임의로 가져오지 않는다.

결과는 영역별 줄 구성·위치·크기·자폭, 조건 판정·경고, 주요 선택 이유와 적용 규칙·패턴, 입력·기준의 식별 정보를 포함한다. UI와 DXF는 같은 배치 결과를 사용한다. 글꼴 미확인 등 입력 문제를 다른 글꼴로 조용히 대체하지 않는다.

후보 선택 순서

적용 조건 확정 → 줄바꿈 후보 생성 → 크기·자폭 맞춤 → 필수 조건 검사 → 문구 묶음 평가 → 정상 후보가 없는 항목의 참고 결과 검토 순서다. 선호 줄 수 안에서 기본 크기를 우선 유지하고 허용 자폭으로 해결되지 않을 때 크기를 축소한다. 정상 후보가 없으면 선호 줄 수 확대·추가 축소를 검토하되 고정 줄 수와 원문·공간·적용 자폭 하한은 지킨다.

규칙의 역할을 후보 생성, 후보 제한, 후보 평가, 결과 설명으로 구분하는 초안이다. 같은 현상을 중복 감점하지 않으며 패턴 평가 전에 후보를 너무 일찍 확정하지 않는다. 후보 평가 함수·탐색 종료·동점 처리·참고 결과의 세부 순위는 아직 미정이다.

조건 충족, 참고 결과 및 확인 필요, 결과를 만들지 못함을 구분한다. 탐색 중단과 수학적 불가능은 다르며 잘못된 입력·시간 제한·계산 실패도 별도 이유로 설명해야 한다. 정상 처리 시간 때문에 몰래 품질을 낮추거나 공간 위반을 정상 결과로 채택하지 않는다.

사용자가 확인한 성능 요구

소량은 배치 버튼을 누르면 거의 바로 결과가 나오는 것을 목표로 한다. 수백 개는 양에 따른 대기를 허용하지만 계산 중임을 알 수 있어야 하고 화면 조작이 멈춘 것처럼 보여서는 안 된다. 초 단위 목표는 아직 정하지 않았다. 외부 규칙 로딩 때문에 반응 속도가 저하되는 방식은 제외한다는 기존 요구를 유지한다.

측정 계획은 실제 작업 PC에서 1개·10개·100개·300개를 나눠 최초 배치와 한 문구 수정 후 재배치를 측정하는 것이다. 입력·선택·화면 이동은 일괄 계산 시간과 별도로 확인한다. 동일 계산 재사용과 영향 없는 결과의 재계산 생략은 최적화 방향이며 구현 방식은 미정이다. 실행 시간에 따라 선택 품질이나 결과가 조용히 달라지지 않도록 검증한다.

v0.8은 적용된 디자인·규칙·입력·배치와 글꼴 측정 자료, 원본 형상을 함께 보존했다. 다시 열기는 엔진 없이 저장된 결과를 읽는다. 다시 계산하기는 시험 당시의 엔진과 측정 조건이 맞는지 확인한다. 기존 엔진이 없으면 재계산을 막아도 저장 결과는 열 수 있다. 글꼴 측정 자료 불일치·내용 손상·알 수 없는 저장 형식도 조용히 통과시키지 않았다.

시험용 공용 기본 자폭을 70%에서 80%로 바꿔도 이전 작업은 바뀌지 않았다. 새 기준을 명시적으로 적용할 때만 별도 개정 결과를 만들었다. 이 변경은 보존 동작을 확인하기 위한 시험이며 실제 고객사 기준을 80%로 변경한 결정이 아니다. 시험의 JSON 형식과 로컬 파일 교체 방법을 제품 저장 구조로 확정하지 않는다.

수정 내용이 실제 출력까지 이어지는지 확인

v0.10에서는 R002의 NO를 MCCB1에서 MCCB9로, R003의 RAT를 40A에서 63A로, R006의 본문을 DC BACKUP에서 DC BACKUP SUPPLY로 변경했다. 수정하지 않은 97행과 수정 행의 다른 영역은 유지됐다. 저장된 배치를 새 실행 과정에서 재계산 없이 출력했고, 실제 DXF에서 세 변경값과 글꼴·정렬·형상을 다시 확인했다. 원래 100행 사례나 고객 발주 원문은 수정하지 않았다.

정상 99행과 MCB46 참고 1행의 구분 및 경고를 유지했다. 출력 생성 중 입력을 바꾸는 시험에서는 임시 결과를 공개하지 않고 이전 출력 파일을 보존했다. 이 검사는 로컬 단일 작성자 환경의 동작이며 Google Drive 동기화나 여러 PC 동시 저장의 안전성을 입증한 것은 아니다.

S1·S2의 장식선 기준 정렬 원인 확인, 디자인별 홀·테두리 여유 수치, 인쇄용 축소 기준은 해당 디자인 검토에서 다룬다. 실제 커터 가공 결과는 현장 확인이 필요하다. Python 시험 통과는 제품 엔진을 Python으로 정했다는 뜻이 아니며 Flutter 기반·Dart 우선·처리 구현 교체 가능이라는 기존 방향을 유지한다.

패턴 목록과 실행 전 검사

목록은 기존 항목을 가져오고 필요한 항목만 추가·수정·제외한다. 제외 취소 시 아래 기준을 다시 따른다. 패턴 제외는 문구 삭제나 강제 분리를 뜻하지 않는다. 같은 표현이어도 분리 제한과 명판 간 통일은 다른 역할이므로 문자열만으로 합치지 않는다. 동일 역할·동일 항목의 식별 기준은 상세 데이터 설계에서 정한다.

STOP P/B와 EM'CY STOP P/B는 둘 다 보존한다. 큰 패턴 내부의 작은 패턴이 독립 줄을 다시 요구하여 큰 표현을 갈라놓지 않게 한다. 모든 경우에 긴 표현이 우선이라는 일반 규칙으로 확대하지 않는다. FEEDER PANEL의 표현을 공유해도 한 줄 또는 FEEDER / PANEL의 실제 구성은 디자인별로 평가한다. 여기서 /는 줄 구분 표시다.

필요한 값·글꼴 누락, 최종 최소값이 최대값보다 큰 모순, 미정 우선순위는 해당 디자인의 실행을 막고 항목·값·출처를 안내한다. 서로 다른 선호는 평가 대상이다. 조건은 정상이나 문구가 긴 상황과 설정 오류를 구분한다. 인쇄에는 커터 규칙을 적용하지 않고, 빈 문구는 일률적으로 차단하지 않는다. 오류 중에도 이전 기록·미리보기는 보존하며 다른 디자인까지 일괄 차단하지 않는다.

45 후보 선택과 계산 종료

정상 배치 선택 순서

원문·홀·허용 경계·적용 자폭 하한 등을 지킨 후보에서 디자인의 선호 줄 수와 기존 커터 조건을 확인한다. 정상 범위에서 영역별로 유지 가능한 가장 큰 글자 크기를 먼저 정하고, 그 크기의 후보들을 개별 평가와 관련 패턴의 조합 평가에 사용한다. 한 영역의 모든 줄은 같은 크기, 자폭은 줄별 조정이다.

선호 1~3줄은 무조건 적은 줄부터 고른다는 뜻이 아니다. 같은 크기의 2줄과 3줄은 해당 디자인의 자폭·균형·패턴 기준으로 비교한다. 개별 점수만으로 한 후보를 먼저 확정하지 않는다. 묶음 평가에 필요한 후보를 보존하고 긴 문구 때문에 다른 정상 항목의 크기를 함께 줄이지 않는다.

동점 초안은 48~49장의 검토안으로 갱신한다. 자폭 주점수는 가장 많이 축소된 줄의 감점으로 계산하고, 모든 규칙과 그룹 평가를 합친 주점수가 정확히 같을 때만 줄별 자폭 감점 합계를 보조 비교한다. 보조 합계까지 같으면 고정된 줄바꿈 비교 순서를 따른다. 입력·완료 순서에 의존하지 않는다. 최종 곡선·가중치·수치 정밀도는 미정이며 저장 결과를 열 때는 다시 선택하지 않는다.

참고 배치 선택과 유지 조건

정상 후보가 없음을 확인한 뒤 선호 줄 수 초과와 추가 크기 축소를 검토한다. 기존 커터 조건을 유지하는 참고 후보를 우선하고 그 안에서 크기를 최대한 살린 뒤 디자인별 평가와 고정 동점 기준으로 하나를 선택하는 초안이다. 그 조건을 유지할 수 없을 때 추가 축소 후보를 검토한다. 실제 사용할 커터를 자동 교체하지 않는다.

참고 결과에서도 원문·공간·고정 줄 수·사용자 전체 줄 구성·영역 및 정렬을 유지한다. 적용 자폭 하한을 무시하여 글자 크기를 살리지 않는다. 축소된 크기의 커터 검토 기준과 원래 기준을 함께 기록하고, 줄 수 초과와 기존 커터 기준 미달을 각각 알린다. 단선체·내부 조각 등 실제 가공 품질은 별도 확인 대상이다. 참고 항목은 정상 명판의 패턴 선택에 참여시키지 않는다.

원문과 엔진 밖의 책임

원문과 배치용 줄바꿈 위치를 별도로 보존한다. EM'CY STOP P/B(ES-A)를 괄호 앞에서 나누어도 원문에 공백을 추가하거나 덮어쓰지 않는다. 사용자가 전체 줄 구성을 지정하면 다른 위치에 자동 개행을 추가하지 않고 크기·자폭·위치를 맞춘다. 원문 편집과 개행 편집의 저장 표현은 상세 설계 대상이다.

공용 기준 변경·승인, 과거 작업에 새 기준 적용, 수량 복제·표기·집계, 프로젝트·자재별 전달 배치, Type3 외부 수정 추적은 텍스트 배치 엔진의 책임이 아니다. 수량은 주문 데이터에 유지하며 수량만 바뀌면 텍스트를 다시 계산하지 않는다. 엔진 교체 시 입출력의 의미를 유지하되 정확한 재계산에는 당시 엔진·측정 조건이 필요하다.

사실과 초안을 구분한다

사용자 PC에서 확인된 것은 제출된 실행 로그의 검사 결과다. 점수곡선 v0.1과 이번 그룹 v0.3은 작성 환경에서만 실행했으며 사용자 미리보기 확인이나 실제 가공 결과로 간주하지 않는다. 각 실행 시간은 여러 검사와 파일 처리를 합친 값이므로 배치 버튼 한 번의 응답 시간이나 제품 성능 목표로 사용하지 않는다.

규칙 연결은 기존 36×36 본문 영역의 기본 자폭·선호 줄 수·등록 패턴 적용 여부로 한정했다. 새 곡선·규칙 강도·인쇄·임의 신규 패턴을 기존 엔진에 모두 연결한 것은 아니다. 80%와 90%, 선호 3줄 등의 변경은 시험 조건이며 고객의 실제 기준을 변경하지 않았다.

44~46장의 기대 결과 사례는 일부만 실행 검증으로 이어졌다. 포함 패턴의 일반 결합, 신규 규칙 주입, 인쇄 축소 기준, 실제 작업 UI, 공유 저장 복구와 형상 오차 계약 등은 여전히 남아 있다. 이번 수학 시험에서 검사 수가 늘었다는 이유로 해당 범위까지 완료 처리하지 않는다.

48 자폭 점수와 동점 처리 초안

필수 공간 조건을 지킨 후보에서 디자인의 선호 줄 수·기존 커터 조건을 확인하고, 항목과 영역별로 유지 가능한 최대 글자 크기를 먼저 선택한다. 남은 같은 크기의 정상 후보에만 개별 점수와 그룹 평가를 적용한다. 자폭 점수의 강도를 낮추거나 꺼도 커터 하한·홀 회피·허용 영역 조건이 꺼지지 않는다.

표는 기본 자폭 80%이고 다른 점수 차이가 없는 수학적 사례다. 실제 같은 문구에서 생성된 도안이 아니다. 평균은 A보다 D를 유리하게 만들어 축소되지 않은 줄의 추가로 평가를 개선시켰다. 따라서 평균을 동점 보조로 쓰자는 제안을 철회하고 합계로 수정한다. 합계는 축소된 줄이 늘면 불리해지는 정책이며 모든 디자인에서 미관상 최선이라는 결론은 아니다.

끄기와 수치의 경계

자폭 규칙을 끄면 주점수와 동점 보조 점수 모두 적용하지 않는다. 보조 점수를 숨겨 계속 평가하지 않는다. 합계까지 같을 때만 입력 순서와 무관한 고정 키를 사용한다. 시험에서는 근사값을 동점으로 묶거나 비교 전에 반올림하지 않았다. 최종 제품의 정밀도와 비교 키 표현은 별도 설계한다.

자폭 축소 정도는 시험에서 기본값과 커터 하한 사이를 0~1로 환산하고 1·2·4승 곡선을 비교했다. 이 곡선·강도는 확정 운영값이 아니다. 같은 규칙과 대상의 동일 평가 내역은 한 번만 반영했지만, 서로 다른 규칙이 같은 현상을 감점하는 의미상 중복 제거는 아직 검증하지 않았다.

49 그룹 평가와 후보 보존 조건

그룹 선택의 비교 순서는 개별 주점수 합과 그룹 감점, 동점일 때 자폭 보조 감점 합, 마지막 고정 키 순이다. 한 항목의 개별 주점수만 보고 최종 후보를 먼저 고르지 않는다. 그룹 평가에 다른 영향을 주는 후보는 남겨둔다. 이미 정상 조건과 항목별 최대 크기를 만족한 후보를 대상으로 한다.

같은 정보 안에서 보존할 후보

그룹 평가가 참조하는 모든 정보가 같은 후보끼리 묶고, 그 안에서 개별 주점수 → 자폭 보조 감점 → 고정 키 순으로 하나를 남긴다. 패턴 내부 줄바꿈뿐 아니라 앞뒤 문구와 줄을 공유하는지도 포함한다. 이번 시험은 전체 패턴 비교 정보를 키로 사용하며 실제 제품의 저장 스키마를 확정하지 않는다.

이 조건에서 다른 항목들의 선택을 고정하면, 같은 키의 후보를 더 좋은 대표 후보로 바꾸어도 그룹 감점은 변하지 않는다. 개별 주점수가 줄거나, 같다면 보조 합계가 줄고, 둘 다 같다면 고정 비교가 좋아진다. 따라서 어떤 조합의 최선 결과도 해당 대표 후보들로 대체할 수 있다. 난수 통과 횟수가 아니라 이 교체 조건이 보존의 근거다.

그룹 점수가 실제 자폭 차이·글자 위치·다른 상태를 새로 비교한다면 기존 키만으로 줄여서는 안 된다. 필요한 정보를 키에 추가하거나 보존 방식을 다시 검증할 때까지 축소를 중단한다. 시험 코드는 다른 의존성이 있다고 선언하면 거부하지만, 선언하지 않은 숨은 의존성을 자동으로 발견하지는 않는다.

이번 시험의 점수는 정확한 정수이며 패턴 관계도 가상 데이터다. 후보 생성·형상·폰트·커터·실제 가독성·부동소수점 계산을 검증하지 않는다. 운영 엔진과 고객 기준은 변경하지 않았다. 다음 연결에서는 실제 점수 출력과 그룹 평가의 의존 정보를 명시하고, 이 비교 순서 전체가 보존되는지 확인해야 한다.
