리치원 도안 자동 배치 연결 시험 v0.3

1. nameplate-engine-flow.html을 PC의 Chrome 또는 Edge로 엽니다.
2. 문구와 수량을 입력한 뒤 배치하기를 누릅니다.
3. 문구를 바꾸면 기존 미리보기를 유지합니다. 배치 반영을 눌러 갱신합니다.
4. 줄바꿈 조정에서 개행 위치를 바꾸면 해당 명판만 즉시 다시 표시합니다.
   원문의 문자/공백/기호를 임의로 바꾸지 않습니다.
   문구 자체는 위 문구 입력란에서 바꿉니다.
5. DXF 내보내기 → 출력 확인 → 시험용 DXF 받기로 파일을 생성합니다.

이번에 연결한 범위
- 기존 MRCE 75 × 25 mm 디자인, 외곽 모서리 R2, Ø4 홀 2개.
- 입력 문구 3종과 각 수량. 문구/수량은 수정할 수 있습니다.
- 제공 HY세고딕의 실제 글리프 폭/윤곽 계산.
- 과거 시험 배치 재사용, 공통 패턴 참고, 줄바꿈/줄별 자폭/영역 전체 글자 크기 조정.
- 미리보기와 동일한 줄별 크기/자폭/좌표를 DXF R2000 TEXT로 기록.
- TEXT 문구에만 Unicode escape. 폰트명과 메타데이터는 CP949로 보존. 미리보기의 윤곽은 표시용이며 DXF 글자는 TEXT입니다.
- 수량만큼 실제 도안을 복제합니다. 기본 3종 총 4개입니다.
- 인터넷이나 별도 서버 없이 실행됩니다. 공유 저장소는 연결하지 않았습니다.

시험 조건과 한계
- 영문, 숫자, ASCII 기호만 연결했습니다. 다른 문자는 오류를 표시합니다.
- 최대 28단어/360자, 최대 탐색 4줄, 총 200개까지의 소량 시험입니다.
  이 제한은 최종 제품 요구나 회사 생산 제한이 아닙니다.
- 시험값: 머리 Ø8 + 여유 2 mm, 외곽 여백 2 mm.
  높이 후보 4.5/4.25/4/3.75/3.5 mm, 자폭 후보 55~80%.
  경험 참고값 3 mm/60%의 연속 감점 및 3줄 선호는 이전 실험식을 유지했습니다.
  전사 기준이나 물리적 가공 한계로 확정한 수치가 아닙니다.
- H의 실제 윤곽 높이로 계산했습니다. Type3의 글자 크기 표시와 정밀 대응은 미검증입니다.
- 정보는 엠알씨이 / PH 1.5T 백흑백 / 수량 / 프로젝트(입력된 경우만)을 각각 한 줄로 표시합니다. 정보 편집 기능은 아직 없습니다.
- 과거 데이터는 합성 시험 기록입니다. 실제 회사 과거 납품 도안이 아닙니다.
- 수동 조정 유지 중 문구가 달라지면 자동으로 덮어쓰지 않습니다.
  자동 배치로 되돌리기를 누른 뒤 다시 배치할 수 있습니다.
- 이 화면을 닫으면 입력 및 임시 출력 이력이 사라집니다.
  DXF 다운로드는 실제 파일 생성입니다. 영구 채택 이력/공유/재주문 검색은 미연결입니다.
- 브라우저의 파일 저장 완료 여부는 프로그램이 확인할 수 없습니다.
- Type3 파일 내부 수정은 추적하지 않습니다.

검증한 것
- 기존 Python v0.6 단독 배치 213개와 문자·크기·자폭·좌표 일치.
- 기존 이력 시험의 3개 문구 배치와 일치.
- 행 순서 변경 불변, 과거 배치 유지, 수동 배치 유지, 긴 식별번호 실패 처리.
- 계산된 윤곽 경계가 시험 여백 및 머리 회피 영역을 침범하지 않음.
- initial/manual DXF를 ezdxf로 재독해 오류/자동 수정 0건.
- 4개 명판/8개 홀, TEXT 문자·좌표·높이·자폭·수량 검증.
- 이벤트/상태 연결은 모의 DOM으로 확인. 실제 브라우저 전체 화면 자동 검사는 미실시.
- 글리프 SVG 미리보기는 이미지로 렌더링해 확인.

아직 확인하지 않은 것
- 이 새 DXF를 실제 Type3에 가져왔을 때의 치수·폰트·위치·편집 및 실제 조각.
- 실제 작업자의 작업 시간, 입력 실수, 소량 주문 이용 편의.
- 다른 디자인/폰트/자재/특수 문자, 동시 작업과 영구 이력.

파일
- nameplate-engine-flow.html: 실행 파일. 설치 없이 브라우저에서 열기.
- MRCE_75x25_initial_R2000.dxf: 초기 3종 4개 출력.
- MRCE_75x25_manual_R2000.dxf: 2번 문구를 3줄로 직접 조정한 출력. 미관 권장안이 아닌 편집 유지 시험.
- initial-layouts.json / manual-layouts.json: DXF의 원문·수량·줄별 실제 배치 기록.
- source/: 이번 연결에 사용한 계산/UI 소스와 시험 글리프 데이터.

2026-10-01 v0.3 수정
- 정보: 고객사, 자재·두께·색상, 수량을 각 한 줄로 작성. 프로젝트는 입력된 경우에만 마지막 줄에 표시하며, 없으면 빈 줄 없이 생략.
- 제품 배열은 왼쪽 아래 (0,0)부터 오른쪽으로 3개, 다음 행은 위쪽.
- 정보 4줄은 제품 배열 전체의 왼쪽 위에 배치.
- 명판 TEXT는 가로 중앙 정렬(72=1)과 두 번째 정렬점(11/21)을 명시.
- 세로 정렬은 기준선(73=0)을 유지하고 줄별 기준선 좌표로 묶음 중앙을 맞춤.
- 기존 윤곽 중앙 위치를 유지하도록 전진 폭과 여백을 고려해 정렬점 계산.
- 안내문 4줄은 왼쪽 정렬. 문구·크기·자폭·원문 공백은 유지.
- 새 DXF를 재독해 배열·폰트·정렬 속성·4줄 메모 및 오류 0건 확인.
- 가로 중앙 정렬을 Type3가 실제로 해석한 결과는 재확인 필요.
