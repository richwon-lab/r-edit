리치원 점수·곡선 독립시험 v0.1

실행
압축을 새 폴더에 풀고 Python 3.10 이상으로 experiment.py를 실행하세요.
  python experiment.py
같은 폴더의 preview.html을 열면 도안 비교, 감점 곡선, 점수 내역을 볼 수 있습니다.
별도 패키지·폰트 설치나 인터넷 연결은 필요하지 않습니다.
예상: passed 18 / total 18, 모든 assertions가 true.

이번 시험
배치 후보를 새로 최적화하는 것이 아니라, 같은 두 후보에 강도·곡선을 달리
적용해 선택과 설명이 예상대로 바뀌는지 확인합니다.
두 후보는 기존 36×36 도형, HY세고딕 측정값, 실제 문구로 계산했습니다.
비교용 기본 자폭은 80%입니다. 원본 70% 시험 파일은 변경하지 않습니다.

후보 A: E/R AC220V / FEEDER PANEL
후보 B: E/R AC220V / FEEDER / PANEL

주의: 이번에는 비교 효과를 보려고 FEEDER PANEL을 한 줄로 유지하는
가상 패턴을 사용합니다. 기존 고객의 FEEDER / PANEL 기준을 바꾸지 않습니다.
이 두 후보는 이미 본 시험 조건에서 정상 후보이며 글자 크기가 같습니다.
이들의 우열은 시험 설정에 따라서만 해석해 주세요.

확인할 결과
1. 직선 감점: B 선택
2. 같은 강도, 4승 곡선: A 선택
3. 같은 직선, 자폭 강도를 0.3으로 완화: A 선택
4. 자폭 감점 끄기: A 선택

감점 계산
x = (기본 자폭 - 실제 자폭) / (기본 자폭 - 커터 하한)
각 줄의 x 중 최댓값을 이번 시험의 자폭 축소 정도로 사용합니다.
자폭 감점 = 강도 × x의 1승/2승/4승
패턴 감점 = 패턴 강도 × 불일치 여부(0 또는 1)
총점은 두 감점의 합이며 낮을수록 유리합니다.
4승은 작은 축소에 관대하고 하한 부근에서 급격하게 감점합니다.
기본 자폭과 하한이 같고 정상 자폭을 유지하면 x=0입니다.
이 공식, 최악의 줄 기준 집계, 가중치는 운영 확정값이 아닙니다.
강도는 양수이며 끄기는 enabled=false로 표현합니다.

필수 경계
원문·홀·영역 위반 → 비교 제외
기존 커터·선호 줄 수 미달 → 정상 후보로 선택하지 않음
더 큰 크기의 정상 후보 존재 → 더 작은 크기는 점수 비교에서 제외
정상 후보 없음 → 검토 필요 (이 시험에서 참고 배치를 새로 만들지는 않음)
크기·자폭·영역 위반 후보는 이 경계를 확인하기 위한 인위적 시험 데이터입니다.
실제 생산 승인 파일이나 DXF는 생성하지 않습니다.

중복과 동점
같은 규칙·대상에 대해 내용까지 같은 평가가 반복되면 한 번만 감점합니다.
같은 규칙·대상의 평가 내용이 서로 다르면 오류입니다.
서로 다른 규칙의 의미상 중복은 아직 다루지 않습니다.
동점은 토큰 줄바꿈 위치, 후보 ID 순으로 결정합니다.
이는 독립시험의 고정 기준이며 최종 제품의 동점 정책은 미정입니다.

범위
점수 선택 단계만 검사합니다. 이전 규칙 연결 v0.2를 대체하지 않습니다.
기존 engine_v06.py의 local_cost와 이번 점수를 함께 합산하지 않습니다.
고객별 규칙 레이어 연결, 여러 명판 동시 패턴 최적화, 곡선 편집 UI,
후보 탐색/보존, 새 폰트 측정, 실제 가공 가능성은 이번 범위 밖입니다.
표시 시간은 제한된 후보의 점수 시험 시간이며 전체 배치 속도가 아닙니다.

파일
experiment.py: 실행, 검사, 보고서 생성
scoring.py: 조건 분리, 점수 내역, 선택
engine_v06.py / regions_v05.py / baseline_v02.py: 기존 도형 맞춤 코드
font_metrics.json / fixture_v06.json: 기존 시험 자료
results.json: 검사 결과·실제 후보 좌표·설정별 감점 내역
preview.html: 비교 보고서 (제품 UI 시안이 아님)

반복 실행하면 이 폴더의 results.json과 preview.html만 다시 작성합니다.
다른 폴더의 원본 도안·규칙·기존 시험 파일은 변경하지 않습니다.
