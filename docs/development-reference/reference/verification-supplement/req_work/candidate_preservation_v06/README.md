# 리치원 실발주 통합 시험 v0.6

## 목적

36×36 문구·NO·RAT 명판의 기존 실제 발주 100행을 한 번에 계산합니다. 이전에 조율한 디자인별 줄바꿈·자폭 점수, 같은 계열 문구 묶음, 등록된 패턴의 여러 줄 구성, 영역별 정렬, 예외 분리를 연결했을 때 기존 결과가 유지되는지 확인합니다.

이 코드는 독립 검증용입니다. 제품 엔진 구조·사용자 UI·기술 선택을 확정하는 코드가 아닙니다.

## 실행

1. ZIP을 모두 압축 해제합니다.
2. Python으로 `experiment.py`를 실행합니다. 추가 패키지 설치는 없습니다.
3. 같은 폴더의 `preview.html`을 브라우저로 엽니다.
4. 상세 결과는 `results.json`에 기록됩니다.

Python 3.9 이상을 대상으로 작성했습니다. HY세고딕의 사전 측정값·미리보기용 글자 경로를 포함하므로 시험을 위해 폰트를 따로 설치할 필요는 없습니다. 다른 폰트·임의의 문구를 받는 완성된 도구는 아닙니다.

## 이번에 보는 내용

| 대상 | 확인 사항 |
|---|---|
| 실제 발주 100행 | 원문·행 순서·중복 행의 개별 NO/RAT 유지 |
| 정상 99개 | 이전 정상 결과의 문자·줄바꿈·글자 크기·자폭·좌표 유지 |
| FEEDER PANEL | 기존 `FEEDER / PANEL` 구성 유지 |
| CONTROL PANEL | 기존 `CONTROL / PANEL` 구성 유지 |
| NO / RAT | 왼쪽·오른쪽 정렬, 하단 기준선, 크기 및 자폭 유지 |
| MCB46 | 현재 디자인 조건에서 참고 결과 하나와 경고 표시 |
| 관련된 가상 예외 | FEEDER PANEL 계열에 정상 배치 불가 문구가 추가돼도 정상 선택 결과 유지 |
| 입력 순서 | 행·후보 순서를 바꿔도 동일 결과 |
| 기존 독립 시험 | v0.2 실제 9개와 v0.5 여섯 사례 결과 유지 |

미리보기에는 실제 발주 100개를 원본 순서대로 표시합니다. 각 명판에는 결과 하나만 있습니다. 상단의 확인 필요 목록은 해당 결과로 이동하는 링크이며 별도의 대안이 아닙니다.

## 조건을 새로 바꾸지 않았습니다

- 본문: 3mm, 기본 자폭 70%, 선호 1~6줄, 중앙 중심 정렬.
- NO·RAT: 3mm, 기본 자폭 70%, 이번 디자인은 1줄 고정. 각자 왼쪽·오른쪽 정렬, 하단 기준선 유지.
- 본문 영역 `[2,9,34,33]`mm, 줄 간격은 기존 시험의 `글자 크기 + 1.1mm` 기준입니다.
- 홀은 기존 시험의 중심·크기·추가 회피 거리를 그대로 사용합니다. 현재 값은 시험용 디자인 조건이며 전사 공통값이 아닙니다.
- 기존 36×36 시험의 자폭 축소를 덜 선호하는 점수와 패턴 구성을 옮겼습니다. 75×25의 자폭 80%·1~3줄 점수는 섞지 않았습니다.
- 같은 계열 묶음은 이전 시험의 동일 문구·숫자만 다른 문구·한 항목만 다른 문구 방식입니다. 아직 일반적인 자동 패턴 인식의 완성도를 검증하는 시험은 아닙니다.
- 패턴 규칙은 해당 디자인의 시험 정책입니다. FEEDER / PANEL 등을 모든 고객·디자인에 강제하지 않습니다. 중첩 패턴 간 충돌 전체를 처리하는 제품용 규칙 시스템도 아닙니다.

## MCB46의 이전 참고안과 다른 이유

옛 참고안은 본문 영역 `[2,8,34,34]`mm와 줄 간격 `글자 크기 + 0.7mm`를 별도로 사용한 7줄·2.63mm 결과였습니다. 이번 기본 디자인은 이와 다릅니다. 과거 참고안을 현재 디자인에서 나온 결과처럼 복사하지 않습니다.

이번 계산에서는 현재 영역·홀·줄 간격을 유지한 채 참고 결과를 탐색합니다. 이번 시험 환경에서는 7줄·2.35mm로 나왔으며 다음 두 사항을 경고합니다.

- 선호 1~6줄 초과.
- 기존 0.3mm 커터의 3mm 크기 기준 미달. 0.2mm 기준 검토 필요.

2~3mm 구간은 기존 경험표의 자폭 하한 64%를 적용합니다. 원래 커터 지정은 0.3mm로 유지하고, 작은 커터는 검토 정보로만 표시합니다. 참고 배치는 생산 승인 결과가 아닙니다. 자동으로 영역·줄 간격·커터 지정을 바꾸지 않습니다.

이 극단 사례를 추가로 최적화하거나 작업자에게 여러 대안을 고르게 하지 않습니다. 사람에게 넘길 참고 결과 하나만 표시합니다.

## 검증 방식과 한계

- 정상 99개의 기대값은 기존 `pattern_layout_width_only.json` 결과입니다. 원문과 줄별 문자열이 같고 글자 크기·자폭·좌표의 수치 차이가 1e-8 이내인지 검사합니다. 모든 영역의 결과를 검사합니다.
- 참고 배치는 정상 문구의 패턴 선택에서 제외됩니다. 실제 예외 제거 전후와, 관련 패턴을 가진 가상 예외 추가 전후를 모두 비교합니다.
- 참고 탐색은 공백·마지막 괄호의 합법적인 경계에서만 줄을 나눕니다. 원문을 고치지 않습니다. 가능한 글자 크기를 0.05mm 간격으로 큰 값부터 확인합니다.
- 좁은 영역에 들어갈 수 없는 줄과 수직 공간에 들어갈 수 없는 줄 수를 먼저 제외합니다. 이 제외 방식은 작은 별도 사례에서 모든 조합을 비교한 결과와 대조했습니다. 고정 1줄 조건도 이 검사에 포함됩니다.
- 탐색 한도 도달은 `search_incomplete`로 구분합니다. 배치 불가능으로 판정하거나 완료된 참고 결과로 표시하지 않습니다.
- 최대 크기라는 의미는 이 시험의 크기 간격·줄바꿈 후보 범위 안에서입니다. 연속적인 모든 좌표·크기를 탐색했다는 의미가 아닙니다.
- 폰트는 사전 측정 자료를 사용하고 글자 경계 상자로 충돌을 검사합니다. 실제 가공 가능성을 보증하지 않습니다. Type3의 글자 크기 정의, DXF 입출력, 글꼴 로딩 비용은 이번 범위 밖입니다.
- v0.2와 v0.5는 회귀 검사로 함께 실행합니다. v0.3·v0.4 전체 테스트를 그대로 재실행한 것은 아닙니다.
- 수동 줄바꿈의 기존 여섯 사례는 유지되지만, 수동 편집을 공유 규칙에 반영하는 제품 흐름까지 구현한 것은 아닙니다.
- 도형·장식·다른 폰트·인쇄 디자인·S1/S2 정렬은 이번 시험에 포함하지 않습니다.

## 실행 시간

`normal_generation_and_selection_ms`는 실제 발주의 본문 정상 후보 생성·선택 시간입니다. `reference_ms`는 실제 예외의 참고 배치 탐색 시간입니다. `total_ms`는 데이터 읽기·배치·추가 자동 검사를 포함하고 결과 파일 저장, Python 시작, 브라우저 렌더링은 제외합니다. 특정 PC의 측정값이며 제품 전체 성능을 보증하지 않습니다.

## 파일

- `experiment.py`: 이번 통합 시험.
- `regions_v05.py`, `baseline_v02.py`: 앞서 확인한 독립 시험 코드 재사용.
- `order.json`: 기존에 추출한 8325ECC 발주 100행, 원본 행 번호와 추출 데이터 해시 포함.
- `design_36.json`, `policy.json`: 이번 디자인의 시험 조건·패턴 정책.
- `expected_36.json`, `expected_v02.json`, `expected_v05.json`: 비교 기준 결과.
- `input_v02.json`, `font_metrics.json`: 기존 소규모 시험 조건·폰트 측정 자료.
- `results.json`, `preview.html`: 실행 결과와 미리보기.

고객 문구·공백·구두점은 그대로 유지합니다. 검수·오타 수정 기능은 이번 시험에 포함하지 않습니다.
