리치원 그룹 후보 보존 독립시험 v0.3

실행
Python 3.10 이상으로 experiment.py 실행 후 preview.html을 여세요.
추가 설치나 인터넷 연결은 필요하지 않습니다.
예상: 13/13 검사 통과, 무작위 200개 전체 비교 일치, 순서 변경 200개 일치.

목적
자폭 보조 감점을 동점 처리에 도입한 뒤에도 후보 축소가 최종 선택을 보존하는지 검사합니다.
모든 후보는 이미 정상 조건과 최대 글자 크기를 만족했다고 가정합니다.
실제 글꼴·형상·조각·명판 미관을 평가하는 시험이 아닙니다.

비교 방식
all: 후보를 모두 남겨 모든 조합 비교
signature: 그룹이 비교하는 정보가 같은 후보 중 주점수 → 보조 감점 → 고정 키 순으로 보존
primary_only: 같은 정보라도 보조 감점을 무시하고 보존 (반례 비교용)
top2: 개별 상위 두 개만 보존 (반례 비교용)
internal_only: 패턴의 앞뒤 공유 여부를 버리고 보존 (반례 비교용)

그룹 전체의 선택 순서
1. 개별 주점수의 합 + 그룹 패턴 감점
2. 전체 주점수가 정확히 같을 때 개별 자폭 보조 감점의 합
3. 항목 ID 순서에 따른 고정 비교 키
낮을수록 유리합니다. 입력 배열 순서는 선택 기준이 아닙니다.

성립 조건
이 시험의 그룹 감점은 지정된 패턴 비교 정보에만 의존합니다.
정보가 같은 후보를 더 좋은 개별 후보로 교체해도 그룹 감점이 바뀌지 않아야 합니다.
추후 그룹 평가가 실제 자폭·위치 등 다른 정보까지 비교하면 보존 키를 확장하거나 축소를 중단해야 합니다.
다른 의존성이 있다고 선언하면 시험 코드는 거부합니다.
숨은 코드 의존성을 자동으로 검출하는 기능은 아닙니다.

수치
점수는 정확한 정수 시험값입니다. 실제 곡선·가중치·부동소수점 정밀도를 결정하지 않습니다.
고정 난수 200개는 시험 범위이며 일반 적용의 근거는 위 보존 조건입니다.
13개 통과에는 6개 명시 사례, 200개 난수 문제 및 순서 변경 검사가 포함됩니다.
결과 파일의 primary_only_mismatches는 주점수 또는 보조 점수 또는 최종 후보가 달라진 건수입니다.

결과
results.json: 사례·점수·보존 전후 조합 수·검사 결과
preview.html: 주요 반례와 비교 표
재실행 시 같은 폴더의 두 결과 파일만 덮어씁니다.
기존 패키지·고객 규칙·실제 도안·저장된 과거 배치는 변경하지 않습니다.
Type3 또는 DXF 확인은 필요하지 않습니다.
