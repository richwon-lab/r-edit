리치원 평가중복 독립시험 v0.1

실행: Python 3.10 이상에서 experiment.py를 실행합니다.
추가 설치는 필요 없습니다. 실행 파일 옆에 results.json과 preview.html을 생성합니다.
preview.html은 브라우저에서 열 수 있습니다. 정상 종료 시 15/15입니다.

목적
- 동일 규칙·대상의 중복 유입으로 점수가 달라지지 않는지 확인합니다.
- 고객 배치 기준이 같은 목적·위치의 일반 기준을 명시적으로 대체합니다.
- 후보마다 적용 평가를 바꾸면 잘못된 후보가 선택되는 반례를 확인합니다.
- 다른 위치·영역·평가 목적은 유지하고 자폭 동점 기준을 지킵니다.

설계 가정
- 레이어 결합이 끝난 입력입니다. 같은 식별자의 설정이 다르면 오류입니다.
- 평가 항목 식별은 규칙 ID와 대상(명판, 영역, 발생 위치)의 조합입니다.
- 대체는 명시된 동일 목적·동일 대상에만 허용합니다. 다른 이름의 규칙이
  의미상 같다는 사실을 자동 추론하지 않습니다.
- 한 단계 대체만 시험합니다. 연쇄 대체와 대체 참여 규칙의 사용 중지는
  시험 범위 밖으로 거부합니다. 이를 제품에서 금지하기로 결정한 것은 아닙니다.
- 자폭의 주점수·보조 점수는 고정 시험값입니다. 기존 곡선 모듈을 실행하지 않습니다.
- 후보별 감점은 정확한 음이 아닌 정수입니다. 제품의 수치 정밀도 결정이 아닙니다.
- A/B는 줄 구성 설명을 붙인 가상 후보입니다. 실제 치수와 품질의 우열을 뜻하지 않습니다.

유지되는 경계
실제 문구 후보 생성, 형상, 폰트, 커터, 패턴 인식, 그룹 최적화는 포함하지 않습니다.
기존 시험·엔진·디자인·고객 기준은 수정하지 않았습니다.
이번 시험은 자동 저장 및 편집 동작도 검사하지 않습니다.
results.json에 기록되는 시간은 이 시험 실행 시간이며 제품 성능 목표가 아닙니다.
