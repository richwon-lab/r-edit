리치원 문구 입력 시험 v01

nameplate-order-entry.html을 Chrome 또는 Edge에서 여세요. 설치와 인터넷 연결이 필요하지 않습니다.
고객사와 디자인은 이번 시험에서 엠알씨이 75×25, PH 1.5T 백흑백, HY세고딕으로 고정되어 있습니다.
프로젝트는 필요한 경우만 입력하며 출력 정보의 마지막 줄에 표시됩니다.

소량 작업
1. 첫 행에 문구를 입력하세요. 수량은 기본 1개입니다.
2. 더 필요하면 [행 추가]를 누르세요.
3. [배치 반영] 후 오른쪽 결과를 확인하세요.
4. 필요한 명판의 [줄바꿈]에서 수정한 뒤 [배치 반영]을 누르세요.
5. [DXF 내보내기]에서 수량·프로젝트를 확인한 뒤 파일을 받으세요.

Excel에서 가져오기
- 제목 행을 제외하고 문구 한 열 또는 문구·수량 두 열을 복사하세요.
- [여러 행 붙여넣기]에 붙여넣고 행 수·수량을 확인한 뒤 [행 추가]를 누르세요.
- 기존 문구 아래에 추가됩니다. 맨 처음의 빈 입력 행 하나는 자동으로 대체합니다.
- 수량이 없으면 1개입니다. 중복 행·공백·대소문자는 그대로 유지합니다.
- 셀 내부 줄바꿈·탭은 이번 입력 시험에서 지원하지 않습니다. 줄바꿈은 배치 후 조정하세요.
- Excel 파일 자체를 여는 기능은 없습니다.

확인 동작
- 입력 중 자동으로 줄바꿈이 바뀌지 않습니다. 이전 배치가 있으면 그대로 보입니다.
- 문구 추가·변경·삭제 후에는 [배치 반영]을 해야 출력할 수 있습니다.
- 수량만 바꾸면 재배치하지 않고 출력 개수에 반영합니다.
- 수동 조정한 문구의 내용까지 바꾸면 [자동 배치로 되돌리기]로 직접 조정을 해제한 뒤 배치하세요.
- 문구 없는 예비 명판도 만들 수 있으며 출력 확인에서 수량을 확인해야 합니다.
- 삭제한 행은 마지막 1회에 한해 되돌릴 수 있습니다.
- 12행씩 표시합니다. [배치 반영]과 DXF 출력은 페이지와 무관하게 전체 행을 처리합니다.

출력
- DXF R2000, 편집 가능한 TEXT, 가로 중앙 정렬, 폰트 메타데이터 CP949 유지.
- 수량만큼 도안을 복제합니다. 수량 숫자만 적는 출력 방식은 아직 없습니다.
- 왼쪽 아래부터 오른쪽, 다음 줄은 위쪽으로 배치합니다.
- 정보: 고객사 / 자재·두께·색상 / 수량 / 프로젝트(있을 때만)를 각각 한 줄로 출력합니다.
- 배열은 검토용 3열 격자입니다. 실제 판재 네스팅·NC 생성은 범위 밖입니다.

시험 범위
- 최대 500행 / 복제 합계 2,000개는 이 화면의 시험 제한이며 회사의 최종 생산 기준이 아닙니다.
- 영문·숫자·ASCII 기호만 지원합니다. 입력 중 오타 자동 교정은 하지 않습니다.
- v02 배치 엔진을 연결했습니다. 괄호의 독립 줄 처리, 242/243 같은 부당한 패턴 연결 보완은 남아 있습니다.
- 명시적으로 채택한 DOPPLER / SATELLITE SPEED LOG REMOTE DISPLAY 두 문구의 2줄 배치는 고정 기록으로 재사용합니다.
- 작업 저장·복원·다중 PC 공유는 아직 없습니다. 화면을 닫거나 새로 고치면 입력과 수동 조정은 사라집니다.
- 최종 기술 선택을 위한 시험이며 웹 또는 특정 프레임워크를 제품 기술로 확정한 것은 아닙니다.

검증
- 직접 입력, 일괄 붙여넣기, 원문 보존, 오류 시 기존 자료 유지, 수동 조정 유지, 삭제/되돌리기, 빈 문구 확인, 페이지 전환을 점검했습니다.
- 기존 286행 문구 배치와 입력 화면을 통한 303개 도안 출력 후 DXF 구조를 확인했습니다.
- UI 이벤트 검사는 모의 DOM에서 실행했습니다. 실제 브라우저의 화면 배치와 새 DXF의 Type3 현장 사용성은 사용자 확인이 필요합니다.
