Type3 타이틀·테두리 가져오기 확인 — 수정 02

Type3_title_border_R02_R2000.dxf를 빈 문서에 가져와 확인합니다.
합성 문구로 만든 시험용 도안이며 생산용 발주가 아닙니다.

이번 수정
1. S1/S2의 글자 실제 외곽 중심을 각각 장식선 위/아래 공간의 중앙에 배치했습니다.
   두 영역의 가로 중심도 같은 장식선 중심에 맞췄습니다.
   원본 장식선, 외형, 홀은 변경하지 않았습니다.
2. 테두리의 직선/곡선 모두에서 글자를 안쪽으로 1mm 이상 띄웠습니다.
   1mm는 이번 시험값이며 회사 공통 규칙으로 확정한 값이 아닙니다.
3. 견고딕 연결은 제공된 파일의 실제 이름과 내부 글꼴명으로 수정했습니다.
   파일: (리)HY견고딕_3.TTF / 내부 이름: (리)HY견고딕
   특태고딕 연결 방식은 그대로 유지했습니다. 글꼴 자체를 수정하지 않았습니다.

확인할 부분
- T01~T03: 견고딕이 인식되는지, S1/S2가 장식선과 나란히 중앙에 있는지 확인합니다.
- B01~B03: 글자가 곡선 테두리를 포함해 안쪽에 여유 있게 들어오는지 확인합니다.
- Expected_layout.png는 로컬 글꼴 계산으로 그린 예상 모습입니다. Type3 화면 캡처가 아닙니다.
- 그룹 해제 후 TEXT를 편집할 수 있어야 합니다. 여러 줄은 각각의 TEXT입니다.

T03은 1줄 고정 방어 시험입니다. 두 줄로 바꾸지 않았습니다.
T03 타이틀 7.09mm는 지정 0.7 커터의 크기 기준 미달 경고 대상입니다.
타이틀/서브타이틀의 배치는 이전 시험과 같고 S1/S2만 조정했습니다.
테두리 명판의 자폭 하한 58%와 1~2줄 범위도 유지했습니다.

글꼴은 동봉하지 않았습니다. 제공된 글꼴이 설치된 작업 PC에서 확인합니다.
폰트 이름은 유니코드 이스케이프하지 않고 문구만 변환했습니다.
