# 리치원 후보보존 독립시험 v0.5

이번 목적은 문구·NO·RAT 세 영역이 각자의 디자인 조건을 유지하는지 확인하는 것입니다. 제품 구현 코드나 새 영어 줄바꿈 품질 평가가 아닙니다.

## 실행

1. ZIP을 모두 압축 해제합니다.
2. Python으로 `experiment.py`를 실행합니다. 추가 패키지 설치는 없습니다.
3. 같은 폴더의 `preview.html`을 브라우저로 열어 확인합니다.
4. 상세 좌표·자폭·검사 결과는 `results.json`에 기록됩니다.

Python 3.9 이상을 대상으로 작성했습니다. 기준 폰트의 사전 측정 자료가 포함되어 있어 별도 폰트 설치 없이 이 고정 시험을 실행할 수 있습니다. 다른 문구·폰트를 임의로 넣어 쓰는 완성된 배치 도구는 아닙니다.

## 사례

| 사례 | 변경 | 확인 사항 |
|---|---|---|
| M01 | 기존 발주에서 추출한 DC BACKUP / MCB1 / 32A | 본문 중앙, NO 왼쪽, RAT 오른쪽 정렬 |
| M02 | 본문을 긴 문구로 변경 | 본문 4줄, NO·RAT 결과는 M01과 동일 |
| M03 | NO를 MCB12로 변경 | 본문·RAT 결과는 M01과 동일 |
| M04 | RAT를 16A로 변경 | 본문·NO 결과는 M01과 동일 |
| M05 | 본문의 전체 줄바꿈을 6줄로 지정 | 지정한 줄바꿈 보존, 크기·자폭 자동 계산, NO·RAT 유지 |
| M06 | RAT 조건만 다른 별도 시험 디자인 | RAT 2.5mm·0.2mm 커터 기준, 본문·NO 3mm·0.3mm 기준 유지 |

M02~M06은 독립성 확인을 위한 가상 변경입니다. M06은 디자인 준비 단계에서 영역별 조건이 다른 상황이며 작업 중 명판마다 글자 크기를 수동 조절하도록 제안하는 것이 아닙니다.

## 사용한 조건과 출처

- 기존 36×36 시험의 영역·홀 좌표를 재사용했습니다. 원본 DXF에서 이번에 다시 확인한 값이나 확정된 생산용 디자인이 아닙니다.
- 본문: 3mm, 기본 자폭 70%, 선호 1~6줄, 영역 내 가로·세로 중앙.
- NO·RAT: 3mm, 기본 자폭 70%, 이번 시험은 1줄 고정, 하단 공통 기준선. 각각 왼쪽·오른쪽 정렬.
- 정상 자폭 하한: 0.3mm 커터 조건 58%. M06의 RAT만 0.2mm 조건 64%.
- 홀 중심 (4,18), (32,18)mm, 홀 반지름 2mm + 추가 회피 거리 2mm.
- 좌표 원점은 왼쪽 아래이며 자세한 값은 `input.json`에 있습니다. 이 수치는 다른 명판의 기본값이 아닙니다.
- 글꼴은 기존 HY세고딕 사전 측정값을 사용합니다. 크기는 대문자 H 높이 기준이며 Type3 내부 크기 정의와의 일치는 별도 확인 대상입니다.

## 자동 검사

원문 문자 보존, 영역 경계·홀 회피, 영역 내 동일 글자 크기, 자폭 하한, 정렬·기준선, 다른 영역에 대한 영향 없음, 전체 수동 줄바꿈 보존을 검사합니다. 영역 및 후보 순서와 행 입력 순서를 바꿔도 같은 결과인지 확인합니다. 입력 디자인도 변경하지 않습니다.

기존 v0.2의 9개 실제 문구 선택 결과가 보관된 결과와 같은지도 확인합니다. 이것이 v0.3·v0.4 전체 검사나 전체 실제 발주 재검증을 의미하지는 않습니다.

## 이번 시험의 경계

- 본문 점수는 영역 분리 확인을 위한 단순한 줄 수·자폭 점수입니다. 영어 의미 단위·공통 패턴 판단을 재현하지 않으며 이전에 조율한 줄바꿈을 대체하지 않습니다. 특히 M02의 줄바꿈을 새 승인안으로 취급하지 않습니다.
- M05는 기본 글자 크기로 맞는 수동 6줄 사례만 검사합니다. 수동 줄바꿈 이후 축소·참고 배치를 찾는 전체 탐색은 구현하지 않았습니다.
- 정상 배치만 다룹니다. v0.4의 극단 사례는 기존 합의대로 참고 결과 하나와 경고를 제시하고 사람이 판단하는 별도 범위입니다.
- 글자 경계 상자로 충돌을 검사합니다. 실제 가공 가능성, Type3, DXF 입출력, 글꼴 로딩 시간, 수백 건 성능은 확인하지 않습니다.
- 영역별 커터는 배치 평가의 기준값입니다. 실제 커터 선정·CAM·NC 생성 기능이 아닙니다.
- S1·S2 정렬, 영역끼리 겹치는지 검사, 인쇄의 축소 기준은 포함하지 않습니다.
- `total_ms`는 입력 읽기와 계산·자동 검사를 포함하고 결과 파일 쓰기·브라우저 렌더링·Python 시작 시간은 제외합니다.

원래 문구·공간 조건을 바꾸지 않은 상태에서 이번 독립 검사가 통과하는지가 목적입니다. 실제 UI·제품 설계는 이 파일의 구조에 맞출 필요가 없습니다.
