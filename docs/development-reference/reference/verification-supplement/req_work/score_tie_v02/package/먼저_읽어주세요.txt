리치원 자폭 동점 처리 독립시험 v0.2

실행
Python 3.10 이상으로 experiment.py를 실행하고 preview.html을 여세요.
  python experiment.py
별도 패키지, 폰트 설치, 인터넷 연결은 필요하지 않습니다.
예상 결과: passed 16 / total 16.

이번에 확인된 사항
앞서 제안한 '동점일 때 평균'에도 축소되지 않은 줄을 추가하면 유리해지는 문제가 남습니다.
보고서의 A와 D 비교에서 이 현상을 재현합니다.

수정 제안
1. 주점수의 자폭 감점: 가장 많이 축소된 줄.
2. 모든 규칙을 합친 전체 주점수가 정확히 같을 때만 줄별 자폭 감점 합계.
3. 합계까지 같으면 기존 고정 줄바꿈 순서.

합계를 주점수로 쓰는 것이 아닙니다. 기존 점수 차이는 뒤집지 않습니다.
축소되지 않은 줄은 합계에 0을 더하므로 평가를 개선하거나 악화시키지 않습니다.
축소된 줄이 추가되면 동점 비교에서 불리해집니다. 이것은 정책 선택이며,
합계가 모든 디자인에서 더 아름다운 결과를 보장한다는 뜻은 아닙니다.
자폭 규칙을 끄면 주점수뿐 아니라 동점 처리의 자폭 영향도 0이 됩니다.

아직 운영 기준을 변경하지 않았습니다.
tiebreak.select의 기본 method는 기존 fixed입니다.
mean과 sum은 이번 비교에서만 명시적으로 호출합니다.

미리보기
A~D는 줄별 자폭만 정한 수학적 사례입니다. 실제 문구나 명판 도안이 아닙니다.
막대는 자폭 비율을 나타내며 실제 글자 길이 또는 도형 너비가 아닙니다.
표의 주점수는 다른 감점이 없다고 가정한 자폭 점수입니다.
실제 연결 시험에서는 기존 전체 주점수 뒤에 보조 점수를 붙입니다.

추가 확인
기존 실제 형상의 두 후보에 대해 네 가지 설정의 선택과 주점수 유지도 확인합니다.
자폭 하한 미달·영역 위반 후보는 여전히 정상 후보로 선택할 수 없습니다.
이전 점수곡선 v0.1의 18개 전체 검사를 다시 실행하는 패키지는 아닙니다.
이번에 필요한 16개 검사를 수행합니다.

파일
experiment.py: 실행, 검사, 보고서 생성
tiebreak.py: 평균/합계 동점 비교 실험
scoring.py: 기존 v0.1 주점수와 조건 판정 (변경 없음)
engine_v06.py / regions_v05.py / baseline_v02.py: 기존 형상 계산 코드
font_metrics.json / fixture_v06.json: 기존 시험 자료 (변경 없음)
results.json: 검사 결과, 후보별 집계, 기존 실제 형상 후보의 비교 기록
preview.html: 비교 보고서

재실행하면 같은 폴더의 results.json과 preview.html을 덮어씁니다.
기존 도안·기존 패키지·고객 규칙에는 영향이 없습니다.
DXF·Type3·전체 100개 재배치·실제 가공은 이번 범위에 없습니다.
수치 정밀도와 최종 동점 처리 정책은 아직 미정입니다.
