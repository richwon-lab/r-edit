리치원 수정·저장·DXF 통합 시험 v0.10

바로 확인하기 — Python 실행 없이 가능
1. preview.html을 엽니다.
2. DXF 폴더의 01_Changed4_R2000.dxf를 Type3의 빈 문서에 가져옵니다.
3. 아래 세 가지 변경이 반영됐는지 확인합니다.
   R002 / NO:   MCCB1 → MCCB9
   R003 / RAT:  40A → 63A
   R006 / 본문: DC BACKUP → DC BACKUP SUPPLY
4. 폰트·정렬·자폭·편집 가능한 텍스트도 기존처럼 유지되는지 확인합니다.
   R007은 수정하지 않은 비교용 명판입니다.

위 변경은 모두 가상 시험입니다. 실제 고객의 발주를 수정한 것이 아닙니다.

출력 파일
- 01_Changed4_R2000.dxf: 수정한 3개 + 수정하지 않은 1개. 빠른 확인용.
- 02_Normal99_R2000.dxf: 정상 99개 전체. 01의 4개를 포함합니다.
  두 파일을 함께 생산하거나 같은 문서에 합쳐 가져오는 것이 아닙니다.
- 03_Reference_MCB46_R2000.dxf: 기존과 같은 검토용 1개.
  7줄 / 2.35mm / 기존 0.3mm 커터 크기 기준 미달 경고 유지.
  0.2mm 검토 필요이며 자동 승인하지 않습니다.
- DXF_checks.json: 각 DXF 재읽기 검사와 문자 객체 대응표.

시험 흐름
1. v0.8의 기준 작업 100개를 엽니다.
2. 본문·NO·RAT를 각각 한 곳씩 수정합니다.
3. 배치 버튼에 해당하는 요청으로 기존 엔진을 실행합니다.
4. 현재 입력과 맞는 최신 결과를 작업 파일에 저장합니다.
5. 새 Python 프로세스가 작업 파일을 다시 엽니다.
6. 저장된 배치에서 DXF를 출력합니다. 출력 중 배치를 재계산하지 않습니다.
7. DXF를 다시 읽어 실제 문구·좌표·크기·자폭·정렬·형상을 비교합니다.

보존 확인
- 수정하지 않은 97개 결과는 기존과 정확히 같습니다.
- 수정한 명판에서도 변경하지 않은 텍스트 영역은 기존과 같습니다.
- 디자인·홀·영역·폰트 측정값·규칙은 바꾸지 않았습니다.
- 저장 후 다시 연 100개 결과가 저장 직전 결과와 같습니다.
- 정상 99개와 검토용 MCB46 1개의 구분을 유지합니다.
- 원본 saved_job_r1.json은 수정하지 않습니다.

출력 도중 변경 방어
- 실제 DXF를 임시 폴더에서 생성하고 검사합니다.
- 최종 결과 폴더로 내보내기 직전에 입력이 바뀌면 결과를 폐기합니다.
- 먼저 생성된 출력 폴더는 그대로 유지합니다.
- 전체 파일의 검사가 끝난 뒤 한 결과 폴더로 내보냅니다.
- 로컬 단일 작업자 시험입니다. Google Drive/네트워크 파일 시스템의 동작이나
  실제 Flutter 동시 실행·정전 복구까지 증명한 것은 아닙니다.

직접 실행하여 재검증하기
    python experiment.py

ezdxf가 설치되어 있지 않다는 오류가 나면 같은 Python 환경에서 한 번 설치합니다.
    python -m pip install -r requirements.txt

매번 DXF, DXF_02, DXF_03 ... 새 폴더로 출력합니다.
실행 결과의 dxf_directory와 preview.html이 이번 실행 폴더를 가리킵니다.
기존 출력 폴더는 자동 삭제하거나 덮어쓰지 않습니다.
직접 실행은 선택사항이며 동봉된 DXF와 미리보기 확인에는 설치가 필요 없습니다.

기타 파일
- experiment.py: 이 파일만 실행하세요.
- saved_job_edited.json: 수정 후 완료 배치를 저장한 작업.
- results.json: 통합 검사 결과.
- snapshot_v08.py / state_probe.py: 기존 저장·상태 시험 코드.
- engine_v06.py / baseline_v02.py / regions_v05.py: 기존 배치 엔진 복사본.
- exporter_v07.py: 기존 Type3 확인 출력 방식. 출력 위치·원본 형상 전달 및 시험 표기만 조정.
- requirements.txt: 이 시험의 DXF 라이브러리. 제품 구현 기술을 확정하는 의미는 아닙니다.

현재 범위
- 배치가 완료된 작업 저장과 출력 연결만 검증합니다.
- 미완료 편집 내용의 임시 저장·재시작 복구, 수동 줄바꿈 수정, 수량,
  여러 디자인 동시 작업, 실제 조각은 이번 범위 밖입니다.
- v0.7의 Type3 호환은 사용자 확인 완료입니다.
  이번 v0.10 수정 파일의 실제 Type3 표시는 아직 사용자 확인이 필요합니다.
- 모든 파일은 시험용이며 생산용이 아닙니다. 명판은 각 1개만 배치했습니다.
