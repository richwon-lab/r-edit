Type3 타이틀·테두리 명판 가져오기 확인

이 파일은 합성 문구로 만든 확인용 도안입니다. 생산용 발주가 아닙니다.

1. Type3의 빈 문서에서 Type3_title_border_R2000.dxf를 가져옵니다.
2. Expected_layout.png와 비교합니다. 그림은 보기 편하게 재배열했으며, DXF는 좌하단부터 오른쪽·위쪽 순서입니다.
3. T01~T03의 견고딕과 B01~B03의 특태고딕이 맞게 보이는지 확인합니다.
4. 글자가 장식·테두리·홀을 침범하지 않는지, 위치와 줄바꿈이 그림과 같은지 확인합니다.
5. 그룹 해제 후 글자 하나를 편집할 수 있는지 확인합니다. 글자 윤곽선이 아닌 TEXT 객체여야 합니다.
6. 명판 크기: T01~T03은 320×65mm, B01~B03은 60×20mm입니다.

T03은 1줄 고정 방어 시험입니다. 두 줄로 바꾸면 안 됩니다.
T03 타이틀은 7.09mm·약 56.02%이며, 지정 0.7 커터의 글자 크기 기준 미달 경고 대상입니다.
다른 타이틀과 섞어서 정상 생산 대상으로 판단하지 마세요.

폰트 파일은 동봉하지 않았습니다. 제공한 HY견고딕·HY특태고딕이 설치된 작업 PC에서 확인합니다.
문구만 유니코드 이스케이프 처리했고, 폰트 이름은 그대로 보존했습니다.
문구별 속성과 파일 자체 검사는 Verification.json에 있습니다. Type3에서는 아직 확인하지 않았습니다.

미확정 시험 조건: 텍스트 영역·여백, 홀 추가 여유 2mm, 글꼴 높이 환산, 테두리 명판의 수직 중앙 정렬.
문제 발생 시 T/B 번호와 화면을 알려주세요. 폰트 / 위치 / 글자 크기 / 직접 편집 중 어느 부분인지 구분해주면 됩니다.
