리치원 패턴 등록 전 영향 확인·적용 시험 v0.1

실행
  cd pattern_apply_v01
  python experiment.py
필요한 경우: python -m pip install -r requirements.txt
실행 후 results.json, preview.html, pattern_preview.json을 확인합니다.
DXF 폴더가 있으면 다음 실행은 DXF_02, DXF_03처럼 새 폴더에 출력합니다.

이번 시험의 작업 흐름
1. 기존 100행 / 300영역 자동 기준을 재현합니다.
2. R028만 지정한 4줄로 수동 배치하고 수량을 2부로 설정합니다.
3. 사용자가 명시한 MONITORING / PANEL 두 줄 규칙을 준비합니다.
4. 자동 대상 R026·R027과 수동 제외 R028을 확인합니다. 실제 배치 변경은 R027 하나입니다.
5. 취소하면 현재 작업을 유지합니다. 적용하면 규칙과 확인한 결과가 함께 반영됩니다.
6. 저장·재열기·R027 후속 수정·DXF 출력까지 검증합니다.

적용 범위
현재 작업의 자동 본문만 대상으로 합니다. 사용자가 원문 문구, 토큰 사이 줄바꿈,
앞뒤 문구와 분리하는 독립 블록을 명시합니다. 자동 패턴 추론은 하지 않습니다.
수동 배치는 패턴의 학습 자료가 되지 않으며 자동 적용 대상에서도 제외합니다.
문자·공백·순서는 원문 그대로 유지합니다. 기존 커터·홀 검사·점수는 유지합니다.

미리보기 안전성
미리보기는 작업을 바꾸지 않습니다. 화면용 사본을 고쳐도 준비한 결과가 바뀌지 않습니다.
미리보기 후 입력·수량·출력 방식이 바뀌거나 작업을 다시 열면 적용을 거부합니다.
패턴을 만족하지 않는 참고 후보는 자동 계산의 최종 검사에서도 거부합니다.
기존 패턴과 같은 문구는 덮어쓰지 않습니다. 수정·삭제는 이 시험에 없습니다.
그룹 일부만 일치하거나 현재 탐색에서 규칙을 지킬 후보를 확보하지 못하면
등록과 적용을 모두 보류합니다. 모든 가능한 배치가 불가능하다는 판정은 아닙니다.

비교 출력
01_BeforePattern: 수동 R028 유지, 패턴 등록 전
02_PatternApplied: 자동 R026·R027에 패턴 명시 적용 후
03_AfterAutomaticEdit: 등록 후 R027 INLET→INLET1 수정
각 폴더의 정상/참고 DXF는 편집 가능한 R2000 TEXT입니다.

범위 밖
실제 UI, 고객사·프로젝트 간 공유, 기존 패턴 수정·삭제, 자동 규칙 추론,
수동 원문 교체, 새 디자인·형상, Type3 추가 검증, 생산 적용.
preview.html은 동작하는 등록 화면이 아닌 시험 결과를 보여주는 정적 페이지입니다.
수량은 시험용 명시값입니다. 동시 사용자 및 클라우드 충돌을 다루지 않습니다.

기준 입력 saved_with_reasons.json은 이전 엔진 정보 그대로 보관합니다.
새 시험에는 현재 엔진 정보와 이전 입력의 연결을 기록합니다.
기존 생산 프로그램은 변경하지 않습니다.
