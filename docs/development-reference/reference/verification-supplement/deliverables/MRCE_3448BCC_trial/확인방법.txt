3448 BCC · 실제 문구 배치 시험

1. review.html을 열어 원문과 줄바꿈을 비교합니다. 번호는 Excel 원본 행과 연결되어 있습니다.
2. DXF를 Type3로 가져와 글자 위치·폰트·자폭이 검토본과 같은지 확인합니다.
3. 수정이 필요한 경우 번호와 원하는 줄바꿈을 적습니다. 원문은 임의로 바꾸지 않습니다.

수량 열이 없는 원본입니다. 각 행을 1개로 만든 286개는 시험 수량이며 생산 수량 확정이 아닙니다.
3열 배열은 검토용이며 판재 배치/NC 생성 범위가 아닙니다.
현재 3개 입력란의 프로그램과 별도로 실행한 전체 발주 엔진 시험입니다. 전체 발주 입력 UI의 작업성은 아직 검증하지 않았습니다.
실제 작업시간을 확인하려면 문구 준비, 배치 후 수정, Type3 재수정 시간을 각각 기록하면 됩니다.
