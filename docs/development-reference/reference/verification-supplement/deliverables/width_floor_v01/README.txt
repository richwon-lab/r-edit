리치원 자동·수동 자폭 하한 처리 일치시험 v0.1

실행
1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. experiment.py를 실행합니다. 예상 결과: passed 24 / total 24, 정상 종료.
3. preview.html에서 수정 전후의 별도 시험 사례를 확인합니다.
ezdxf가 없으면 현재 사용하는 Python 환경에서 아래 명령을 실행합니다.
    python -m pip install -r requirements.txt

수정 이유
기존 자동 참고 탐색은 축소 구간의 자폭 하한이 미등록이면 이를 0으로 취급했습니다.
W 80자의 별도 시험에서 1.95mm·자폭 약 11.11%의 참고 결과를 반환했습니다.
이 결과는 회귀 문제 재현용 기록이며 새 DXF로 출력하지 않습니다.

이번 변경
자동 참고 탐색도 수동 맞춤과 같이 미등록 자폭 하한이 필요한 구간에서 멈춥니다.
배치를 만들지 않고 계산 불가(calculation_unavailable)로 기록합니다.
width_floor_unregistered 이유와 해당 높이·검토 커터 구간을 남깁니다.
이미 관찰한 정상·참고 탐색 내역도 유지합니다.
설정 누락은 후보 검사 횟수에 포함하지 않습니다.
표시 문구는 글꼴 문제로 안내하지 않고 자폭 하한 등록이 필요함을 알립니다.
사용할 공구나 자폭 하한 값을 새로 정하지 않았습니다.

검사 결과
- 기존 100행·300영역의 배치·상태·경고·진단 내역 모두 유지.
- 정상 99행·참고 MCB46 1행 유지.
- 자동·수동의 미등록 하한 처리 및 안내 일치.
- 등록된 2.0mm 구간의 자폭 하한 64%를 지키는 참고 결과 유지.
- 탐색 미완료, 글꼴 측정 누락, NO 영역 배치 없음은 각 상태로 유지.
- 저장·복원 후에도 미등록 이유와 수동 전체 줄 구성 유지.
- 자동·수동 모두 해당 명판 전체를 DXF에서 제외하고 이유 기록.

생성 파일
results.json: 검사 결과.
preview.html: 수정 전후 비교 보고서.
comparison.json: 이전 결과 재현, 수정 후 자동·수동 결과, 등록 구간 사례.
saved_auto_cases.json / saved_manual_cases.json: 별도 3행 시험 저장본.
DXF/01_Automatic, DXF/02_Manual: 각 묶음 정상 1개·참고 1개·제외 1개.
export_report.json: 출력 포함·참고·제외 내역과 이유.
재실행 시 DXF_02, DXF_03처럼 새 폴더를 만듭니다.
두 묶음은 같은 문구의 자동·수동 비교용이며 합쳐서 생산하지 않습니다.

구현 변경 파일
engine_v06.py: 미등록 하한에서 배치를 반환하지 않도록 수정.
reporting.py: 설정 누락 이유를 후보 검사 내역과 분리해 전달.
diagnostics.py: 자폭 하한 누락에 맞는 안내 문구.
그 외 배치·수동 편집·저장·DXF 모듈은 manual_flow_v01에서 그대로 복사했습니다.
legacy_engine_v06.py는 문제 재현용 이전 코드이며 실제 새 배치 경로에서 사용하지 않습니다.
saved_with_reasons.json은 변경하지 않는 이전 자동 결과 기준 자료입니다.

제한
기존 36×36mm·홀 2개·HY 측정 자료의 독립 시험입니다.
이 시험의 등록된 커터 구간 수치를 모든 디자인에 적용하는 기준으로 확정하지 않습니다.
미등록 구간을 사용하려면 실제 적용할 기준을 별도로 정해야 합니다.
제품 UI, 새로운 후보 점수, 인쇄 정책, 수량, 형상 확장, 생산 승인, Type3 현장 확인은 포함하지 않습니다.
기존 저장 파일을 자동으로 변경하거나 과거 출력물을 덮어쓰지 않습니다.
