리치원 개별 수동 줄바꿈·패턴 분리와 자동 그룹 재계산 시험 v0.1

확인된 운영 원칙 — 2026-10-12 사용자 설명 반영
  수동 작업과 패턴 지정은 서로 다른 동작입니다.
  과거 명판의 줄바꿈을 맞추기 위한 단발성 수동 작업이 있을 수 있습니다.
  수동 줄 구성은 해당 명판·영역의 개별 지정으로 유지합니다.
  여러 명판에 전파할 줄바꿈은 규칙성을 파악하고 패턴으로 별도 등록합니다.
  수동 작업만으로 패턴이나 공통 규칙을 자동 생성·수정하지 않습니다.

UI/UX 안내 방향
  수동 줄바꿈 작업에는 '이 명판에만 적용'이라는 범위를 분명하게 보여줍니다.
  여러 명판에도 적용하려는 경우에는 '패턴 등록' 작업으로 안내합니다.
  패턴 등록에서는 반복되는 문구·줄 구성 규칙, 적용 범위, 영향받는 명판을 검토합니다.
  한 명판의 수동 줄바꿈을 그대로 모든 문구에 복사하는 기능으로 취급하지 않습니다.
  이 자료는 작업 구분과 안내 방향을 기록합니다. 실제 UI 및 규칙 추론은 구현하지 않았습니다.

실행
  python -m pip install -r requirements.txt
  python experiment.py

Python 3.12에서 37/37 통과했습니다. Windows Python 3.14 실행 결과는 별도 확인 대상입니다.
preview.html과 DXF/는 미리 생성되어 있습니다. 재실행하면 기존 출력 폴더를
덮어쓰지 않고 DXF_02, DXF_03 등 새 폴더에 출력합니다.

구현한 범위
  수동 지정 직후에는 다른 명판의 배치를 바꾸지 않습니다.
  자동 본문 수정 시 수정 전·후의 자동 그룹 관계를 함께 검사합니다.
  수동 본문은 자동 그룹의 입력에서 제외하고 저장된 결과를 유지합니다.
  검사 범위는 기존 관계의 연결을 따라 보수적으로 잡습니다.
  검사 대상 수가 실제 배치 변경 수를 의미하지는 않습니다.
  자동 복귀를 선택한 영역은 자동 계산하되, 다른 수동 본문을 그룹 기준으로 쓰지 않습니다.
  기존 등록 패턴과 점수, 커터, 형상 조건은 그대로 적용합니다.

주요 사례
  기존 자동 기준 100행/300영역 결과 변경 0개.
  R028 OUTLET 문구를 개별 수동 4줄로 지정하고 다른 99행이 그대로인지 확인합니다.
  R027 INLET 문구를 INLET1로, RAT를 20A로 바꿉니다.
  R027 본문·RAT만 갱신하며 다른 298개 영역 결과를 유지합니다.
  R028을 다른 유효한 5줄 구성으로 바꾸어도 R027 자동 결과는 동일합니다.
  R027 자동 복귀 시에도 R028의 수동 구성이 전파되지 않습니다.
  기존 FEEDER / PANEL 등록 패턴은 자동 본문 변경 후에도 적용됩니다.
  R019를 SPARE로 바꾸면 이전 REMOTE LAMP BOX 그룹과 새 SPARE 그룹의
  자동 본문 14개를 검사하며 무관한 명판과 모든 NO/RAT 결과는 유지합니다.
  본문에 측정 자료가 없는 문자를 넣으면 해당 명판 전체를 출력에서 제외합니다.
  교정하면 해당 명판을 다시 출력하고 오래된 오류 사유는 남기지 않습니다.
  R028 수량 2, 나머지 1은 연결 동작을 검증하기 위한 가상 시험 수량입니다.

파일
  main_group.py: 수정 전후 자동 그룹 영향 범위 및 해당 본문·수정 NO/RAT 계산.
  reporting.py: 기존 본문 계산을 공유 함수로 분리(선택 기준 변경 없음).
  manual_workflow.py: 자동 복귀 시 다른 수동 본문을 자동 그룹에서 제외.
  draft_store.py / state_probe.py: 초안의 자동 본문 변경 요청 연결.
  snapshot_v08.py: 새 계산 모듈도 엔진 식별 정보에 포함.
  saved_with_reasons.json: 이전 시험 원본(수정하지 않음).
  saved_manual_baseline.json: R028 개별 수동 지정 완료.
  saved_group_pending.json / saved_group_completed.json: R027 수정 초안 / 완료.
  saved_group_move.json: R019가 다른 자동 그룹으로 이동한 결과.
  saved_registered_pattern.json: 기존 등록 패턴 유지 사례.
  saved_group_failure.json / saved_group_corrected.json: 본문 실패 / 교정.
  DXF/01_MainEdited, 02_MainFailure, 03_MainCorrected: 각 결과의 정상·참고 DXF와 출력 내역.

저장·출력
  미계산 입력에서는 이전 배치를 현재 결과로 출력하지 않습니다.
  늦게 도착한 계산 결과와 다른 세션 결과는 거부합니다.
  완료 결과는 새 프로세스에서 배치 엔진을 불러오지 않고 출력할 수 있습니다.
  새 시험 엔진으로 명시적으로 계산하며 과거 결과의 엔진 식별 정보를 덮어쓰지 않습니다.

미포함
  패턴 등록 화면, 자동 패턴 추론, 수동 영역 원문 교체, 여러 수동 구성의 동시 편집,
  행 추가·삭제·순서 변경, 디자인·규칙 변경, Type3 검증 및 생산 적용.
  기존 패턴의 그룹 일부 적용 등 기존 시험 엔진이 지원하지 않는 경우를 새로 해결하지 않습니다.
  사용자 설명은 위 원칙으로 기록하며 원본 요구사항 Word 파일은 수정하지 않았습니다.
