리치원 수동 본문 유지·NO/RAT 수정 재계산 시험 v0.1

실행
  python -m pip install -r requirements.txt
  python experiment.py

Python 3.12에서 35/35 통과했습니다. Windows Python 3.14 실행 결과는 별도 확인 대상입니다.
preview.html과 DXF/는 미리 생성되어 있습니다. 재실행하면 DXF_02, DXF_03 등
새 폴더에 출력하며 이전 출력 폴더를 덮어쓰지 않습니다.

이번에 연결한 동작
  수동 본문이 있는 작업에서 자동 NO/RAT 영역의 원문을 수정합니다.
  저장·재열기 후 수정한 NO/RAT만 기존 영역별 계산기로 다시 계산합니다.
  나머지 배치와 진단, 수동 본문의 줄 구성, 수량은 그대로 보존합니다.
  자동 본문 그룹 선택은 이 재계산 경로에서 호출하지 않습니다.

시험 자료
  기존 자동 100행/300영역 결과를 먼저 비교합니다(변경 0개).
  R005를 앞서 확인한 수동 한 줄 참고 배치로 계산합니다(2.3mm).
  이 상태에서 R002 RAT=20A, R005 RAT=10A, R006 NO=F99로 수정합니다.
  수정한 3개 영역만 계산하고 나머지 297개 영역은 정확히 유지합니다.
  수량은 R002=4, R005=2, 나머지=1인 가상 시험값입니다. 총 104개입니다.
  실제 주문 수량을 의미하지 않습니다.

실패·교정 사례
  R007 RAT에 측정 자료가 없는 문자를 넣으면 계산 불가입니다.
  R008 NO에 W 80자를 넣으면 현재 탐색에서 배치 없음입니다.
  두 경우를 구분해 저장하고 해당 명판 전체를 DXF에서 제외합니다.
  R007을 10A로 고치면 그 명판만 다시 출력하며 R008은 계속 제외합니다.
  교정한 영역의 옛 실패 사유는 남기지 않고 다른 영역의 진단은 보존합니다.

주요 파일
  mixed_footer.py: 변경 범위 검사, 수정한 자동 NO/RAT만 계산하는 연결 모듈.
  reporting.py: 기존 NO/RAT 계산을 공유 함수로 분리. 전체 자동 계산과 동일 함수 사용.
  state_probe.py: 해당 계산 요청을 새 연결 모듈로 전달.
  draft_store.py: 수동 배치와 NO/RAT 수정이 섞인 초안의 재계산 요청 연결.
  snapshot_v08.py: 새 계산 모듈도 엔진 식별 정보에 포함.
  experiment.py: 회귀, 상태, 실제 DXF 검증.
  saved_with_reasons.json / saved_draft_manual_completed.json: 이전 시험 원본(변경하지 않음).
  saved_mixed_baseline.json: 새 시험 엔진에서 재계산해 검증한 수동 본문 기준 상태.
  saved_mixed_pending.json: NO/RAT 수정 후 재계산 전 초안.
  saved_mixed_completed.json: 세 영역 재계산 완료.
  saved_mixed_failures.json: 두 명판의 실패 상태.
  saved_mixed_corrected.json: 한 명판 교정 완료.
  DXF/01_MixedCompleted: 정상 101개 + 참고 3개 = 도안 104개.
  DXF/02_FooterFailures: 정상 99개 + 참고 3개 = 도안 102개, 2개 제외.
  DXF/03_OneCorrected: 정상 100개 + 참고 3개 = 도안 103개, 1개 제외.
  각 폴더에 실제 DXF와 export_report.json이 있습니다.

검증 범위
  전체 자동 기준 결과 및 과거 수동 배치와 정확히 일치하는지 확인합니다.
  수정 영역 결과는 기존 전체 자동 계산의 동일 영역 결과와 비교합니다.
  오래된 계산 완료, 저장 중 계산 상태, 엔진·글꼴 불일치를 확인합니다.
  과거 엔진의 완료 결과는 다시 열 수 있지만 새 엔진 결과로 재표시하지 않습니다.
  새 시험은 부모 입력 식별 정보와 현재 코드 식별 정보를 명시적으로 기록합니다.
  완료 결과를 별도 프로세스에서 엔진 import 없이 다시 열고 출력합니다.
  실제 DXF에 새 NO/RAT와 수동 한 줄 복제 도안이 들어가는지 확인합니다.

미포함
  자동 본문 변경에 따른 그룹 재계산, 수동 영역의 원문 교체, 수동 줄 구성과
  NO/RAT 원문을 동시에 바꾸는 일반 편집, 행 추가·삭제·순서 변경, 디자인·규칙 변경.
  이러한 변경이 이번 대상 계산에 섞이면 조용히 무시하지 않고 거부합니다.
  기존 단일 수동 변경·자동 복귀 경로는 그대로 유지합니다.
  배치 점수·커터·형상 조건, 수량 출력 정책, 실제 UI, Type3 및 생산 적용은 변경하지 않습니다.
