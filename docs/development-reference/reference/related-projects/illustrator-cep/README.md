# 리치원 명판 도구 — CEP MVP 0.1

현재 구현 범위: **명판 간격 조정 MVP**

## 구현됨
- 선택한 객체에서 최외곽 폐곡선을 이용해 명판 단위 자동 인식
- 문자/선/내부 도형을 명판 외곽 안의 소속 객체로 묶어 함께 이동
- 현재 배열의 열/행 수 자동 인식
- 좌상단 명판 고정
- 가로/세로 간격 독립 설정
- 0/20/30mm 프리셋 (설정에서 변경 가능)
- 가로 배치 개수 변경
- 예상 배열/전체 크기 표시
- 인쇄기 프로필 등록 및 폭 초과 경고
- 장비별 `폭에 맞춤`: 가로 개수는 유지하고 가로 간격만 축소

## 아직 구현하지 않음
- 샤링 재단 표시 생성
- R 자동 추천/표기
- 판재 크기 표기
- 홀 후보/반복패턴/펀치 라이브러리/홀 크기 표기

## 현재 MVP의 입력 전제
- 명판마다 **최외곽 폐곡선**이 1개 존재합니다.
- 명판끼리는 겹치지 않습니다.
- 명판 내부 콘텐츠는 해당 최외곽선 안에 있습니다.
- 간격 조정 전 명판 사이 간격은 0보다 큰 상태를 우선 테스트 대상으로 합니다.
- 여러 명판을 통째로 하나의 Illustrator 그룹으로 묶은 선택은 아직 지원하지 않습니다. 명판별 그룹 또는 비그룹 객체는 테스트 대상입니다.

## 설치 — Windows 개발 테스트
1. Illustrator를 종료합니다.
2. `enable-debug-windows.reg`를 실행합니다. (CEP 9~12 PlayerDebugMode 활성화)
3. 이 `richwon-nameplate-tools` 폴더 전체를 아래 위치에 복사합니다.
   - `%APPDATA%\Adobe\CEP\extensions\richwon-nameplate-tools`
   - 폴더가 없으면 직접 만듭니다.
4. Illustrator를 다시 실행합니다.
5. `창(Window) > 확장 기능(Extensions)` 또는 버전에 따라 `확장 기능(레거시)`에서 **리치원 명판 도구**를 엽니다.

## 설치 — macOS 개발 테스트
1. Illustrator를 종료합니다.
2. `enable-debug-macos.command`를 실행합니다.
3. 폴더 전체를 `~/Library/Application Support/Adobe/CEP/extensions/richwon-nameplate-tools`에 복사합니다.
4. Illustrator를 재실행하고 Window > Extensions 계열 메뉴에서 패널을 엽니다.

## 첫 테스트 방법
1. **사본 도안**에서 테스트하십시오.
2. 동일 크기 명판 6~12개를 간격이 있는 상태로 배치합니다.
3. 외곽선, 문자, 내부 선/원 등을 포함해 전체 명판을 드래그 선택합니다.
4. 패널의 `선택 다시 읽기`를 누릅니다.
5. `인식 명판`과 현재 열/행 수가 실제와 맞는지 먼저 확인합니다.
6. 간격 20~30mm로 적용해 보고, 좌상단 명판이 움직이지 않는지 확인합니다.
7. 열 수를 바꿔 재배치해 봅니다.
8. 장비 프로필 폭보다 넓게 만든 뒤 `폭에 맞춤`을 테스트합니다.

## 실패 시 확인할 것
- `명판 최외곽 폐곡선을 찾지 못했습니다`: 외곽 패스가 닫혀 있는지 확인
- `일부 선택 객체를 명판에 연결하지 못했습니다`: 여러 명판을 하나로 그룹했거나 명판 외부 객체를 함께 선택했는지 확인
- `가로 간격을 0mm까지 줄여도...`: 열 수를 줄여야 함

## 개발 메모
- UI: CEP HTML/CSS/JS
- Illustrator DOM: ExtendScript `host/index.jsx`
- 좌표/크기 판단: `geometricBounds`
- 이동: 각 명판에 소속된 선택 최상위 PageItem을 `translate()`로 동일 이동
- 결과를 테스트하면서 외곽 인식 예외를 먼저 안정화한 뒤 샤링/홀 기능을 추가하는 구조입니다.
